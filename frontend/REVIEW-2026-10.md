# P0（1 条）

## P0-1 `timelineEntries` 合并同名附件时去重失效

- **位置**：`src/features/workbench/components/deal-detail/detail-domain.ts:269`
- **状态**：确证

```ts
const seenNames = new Set(exist.atts.map((a) => a.name))
for (const a of l.atts) if (!seenNames.has(a.name)) exist.atts.push(a)   // 缺 .add()
```

`seenNames` 创建后从未 `.add()`，跨轮次合并时去重失效。对照同函数新建路径（`:274-280`）是正确的，属笔误。

**影响**：≥3 条同内容日志各带同名附件时，同一附件在时间轴重复出现，`attN` 计数虚高。

**修复**：

```ts
for (const a of l.atts) if (!seenNames.has(a.name)) { seenNames.add(a.name); exist.atts.push(a) }
```
