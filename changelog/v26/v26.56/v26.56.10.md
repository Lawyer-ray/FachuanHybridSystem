# v26.56.10

> 分支：`research/ocr-quick-fill`（快速填充 OCR 判决书叙述式提取 + Admin 多处 UI 修复 + LPR 计算器 Alpine 修复）

## 后端

### 新功能

#### feat(client): OCR 规则提取健壮性增强（纯规则，不引入 LLM）

- 身份证号 ISO 7064 MOD 11-2 校验、统一社会信用代码 GB 32100 校验，多候选时选校验通过者；校验失败不丢弃，置信度降级并提示人工核对
- OCR 文本归一化前置：全角数字/字母/标点转半角、去除行内空白
- 提取服务健壮性增强（详见 commit `225515ae`）

### 修复

#### fix(client): 快速填充 OCR 支持判决书叙述式文本提取

- 身份证卡片版式之外，新增判决书/起诉状叙述式文本（「被告三：陈达良，男，汉族，…住…」）的姓名、身份证号、地址等字段回退提取
- 修复 `id_number` 命中即提前返回、不再走 LLM 兜底的问题

#### fix(contracts): 合同 admin 律所OA字段移除冗余 help_text

- 「律所OA链接」「律所OA案件编号」的 help_text 与字段名重复，直接删除（含迁移）

#### fix(contacts): 案件工作人员 inline 布局修复

- 编辑页案件工作人员由 Stacked 改为 Tabular 紧凑布局，与同页其他 inline 一致
- 修复 tabular 表格因 vTextField 固定 20em 宽导致的横向溢出（`table-layout: fixed` + 输入框撑满单元格）

#### fix(cases): 案件编辑页文案与提示清理

- 删除「前序案件」字段冗余 help_text（该案的前一个审理阶段，如二审案件指向前一审案件）
- 财产保全金额/涉案金额为空时不再显示「请输入财产保全金额」「请输入涉案金额」占位提示
- 金额为空时隐藏诉讼费显示容器，避免空灰色块残留

#### fix(finance): LPR 计算器 Alpine 报错与结果不显示修复

- 初始状态 `result`/`mResult` 为 null 时模板表达式疯狂报错：所有 `x-text`/`x-show` 表达式加可选链，`x-for` 数据源补 `|| []` 兜底
- 利息计算结果不显示：表单与结果区原先在两个独立 `lprCalculator()` Alpine 实例中，表单实例的 `result` 赋值后结果区实例读到的仍是 null；改为表单+结果共用一个组件实例（与房贷 tab 结构一致）
