# v26.56.9

> 分支：`investigate/courtsms-183-recommend`（房贷逾期诉讼违约债权计算器全量落地：通用化 4 批迭代、巨石拆分重构、URL 收拢，及文书信息提取修复）

## 后端

### 新功能

#### feat(finance): 房贷逾期诉讼违约债权计算器（tab + API + MCP 工具）

面向银行起诉断供借款人场景，新增：

- `MortgageDefaultCalculator`：等额本息/等额本金摊销 + LPR 重定价 + 还款流水冲抵（顺序可配）+ 罚息（倍数/指定）+ 复利（双开关）+ 提前还款重排，输出诉讼请求汇总与逐期违约明细
- API：`/lpr/amortize`、`/lpr/mortgage-default-calculate`
- MCP 工具：`mortgage_amortize`、`mortgage_default_calculate`
- Admin 计算器页新增「房贷逾期诉讼」tab（批量粘贴流水、冲抵顺序调整、起诉状金额段复制、CSV 导出）

#### feat(finance): 计算器通用化第 1 批——诉讼费合并/利息止算/逾期加码/舍入规则

- 新增银行档案预设 `bank_profiles.py`，参数与核心算法解耦
- 诉讼费用主张可并入诉请总额，并可开关参与还款冲抵
- 支持利息止算日，止算后罚息/复利是否继续可单独控制
- 逾期自动加码：连续逾期天数触发后罚息/复利利率自动上浮
- 舍入规则切换：逐期四舍五入 vs 汇总一次性舍入

#### feat(finance): 计算器通用化第 2 批——银行口径参数完善 + 冲抵顺序拖拽排序

- 冲抵顺序改为 HTML5 拖拽排序，保留预设快速切换
- 抽象 `MORTGAGE_ALLOCATION_CONFIG` 配置、`reorderArray` 纯函数、`buildDefaultForm` 默认表单工厂，init/reset 共用
- 前端表单接入新参数：复利计算方式/宽限期/首期计息/逾期天数口径/提前还款补偿金率，后端 schema/api/MCP 同步新增并带默认值兜底

#### feat(finance): 计算器通用化第 3 批——封顶/计息边界/停息挂账

- 利率/总债权封顶：`cap_penalty_annual` 罚息/复利年利率封顶；`cap_total_mode/value` 违约金+罚息+复利合计封顶（固定金额/未还本金倍数/未付利息倍数）
- 计息起止边界：`interest_cut_inclusive` 含截止日当天（算头算尾，末日各 +1 天）
- 停息挂账：`pause_periods` 停息区间，区间内罚息/复利及按天截算的合同利息暂停计息，还款流水照常核销
- 补接此前未接入 MCP 的 `claim_mode`/`accelerate` 参数

### 重构

#### refactor(finance): 拆分 mortgage_calculator 巨石并按职责规划目录

- 新建 `mortgage_models.py` 收敛常量、金额/日期工具、结果 dataclass 与序列化；随后将 1292 行主算法文件按职责拆分为 `validation`(校验) / `rate_resolver`(利率) / `schedule`(摊销) / `accrual`(计息) / `ledger`(账本) / `simulation`(状态+主循环) / `claim`(诉请汇总) 七个独立模块
- `mortgage_calculator.py` 瘦身为向后兼容门面，lpr_api/MCP/既有测试无需改动
- 纯行为迁移，不改变任何计算结果

#### refactor(finance): 计算器收拢为 LPR利率 模型子页单一 URL

- `/admin/finance/calculator/` 由独立视图改为 302 重定向到模型子页 `/admin/finance/lprrate/calculator/`，消除双入口冗余（旧收藏/书签仍可用）
- 侧边栏「其他工具」子项与默认收藏 URL 统一指向真实模型子页
- 面包屑升级为原生三层：首页 → 金融工具 → LPR利率 → 计算器
- 同步按钮改用模板内 `reverse('admin:finance_lprrate_sync')`，修正相对路径在子页下的解析隐患

#### refactor(finance): 表单精简与样式优化

- 表单与脚本去掉诉讼费用主张区块及 fee 相关字段/函数，避免并入诉讼请求合计的重复设计
- 冲抵顺序仅保留拖拽排序，移除箭头微调与 moveOrder 死代码；清理 stances/FEE_CATEGORIES 等冗余配置
- 复利勾选项改为 toggle 开关样式，并修复开关被 field input 宽度规则拉伸的问题

#### refactor(finance): 移除未经验证的银行口径预设档案

银行档案（交行/工行/建行/中行/农行/招行）为硬编码的常识性起始模板，未经真实合同条款验证，易被误当权威口径用于诉讼主张，现删除仅保留「通用·自定义」；后续如需预置，须以真实合同数据按同一结构增补。

### 修复

#### fix(finance): RateEventSchema 字段名与日期类型同名导致 URL 校验失败

`date: date = Field(...)` 中字段名遮蔽类型，在 `from __future__ import annotations` 下触发 pydantic 同名冲突异常；改用别名导入 `from datetime import date as Date` 规避，字段契约不变。

#### fix(automation): 文书信息提取不再依赖 scraper_task，支持直接读取 document_file_paths

- 移除 `_extract_and_update_sms_from_documents` 中 scraper_task 为空即提前返回的逻辑，收件箱导入等无下载任务的短信也能从文书提取案号与当事人
- `_get_document_paths_for_extraction` 优先收集 `sms.document_file_paths` 中真实存在的文件，并与 scraper_task 文书合并去重

### 其他

#### chore(finance): LPR 种子数据同步至 2026-08-20

补录 2026-07-20 / 2026-08-20 两条月度利率（1Y 3.00%，5Y 3.50%），seed_lpr_rates.json 与数据库记录保持一致（共 87 条）。
