# v26.56.8

> 分支：`fix/oa-credential-per-user`（OA 登录缓存按账号隔离、Django 6.1 邮件/依赖/admin 兼容适配、文书模板默认配置同步）

## 后端

### 修复

#### fix(oa_filing): 金诚同达 OA 登录缓存按账号隔离，避免不同律师复用登录态

**问题**：切换 Django 账号后，金诚同达 OA 登录仍沿用上一账号的会话凭证，导致不同律师复用同一登录态、凭证串号。

**修复**：OA 登录 cookie 缓存文件改为按账号隔离（`jtn_cookies_{账号}.json`），`auth/constants.py`、`auth/service.py`、`filing/sso_login.py`、`archive/playwright_archive.py`、`stamp/playwright_stamp.py` 同步调整；新增按账号隔离的读写回归测试。

#### fix(core): 邮件配置迁移到 Django 6.1 MAILERS，消除废弃告警

**问题**：动态修改 `settings.EMAIL_*` 触发 `RemovedInDjango70Warning`，且 `fail_silently` 参数在 Django 6.1 已废弃。

**修复**：`email_service.py` 改为动态配置 `settings.MAILERS`（SMTP 后端 + host/port/username/password/ssl/tls 选项），`send_mail` 调用移除 `fail_silently` 改用 `using="default"`。

#### fix(admin): 插件 preservation_quote 移除废弃的 wide class

**问题**：Django 6.1 移除 admin 字段集的 `wide` class，保留会导致样式异常。

**修复**：在插件子模块 `court_automation/preservation_quote/admin.py` 中移除 `"classes": ("wide",)` 配置，并同步更新子模块指针。

#### fix(dependencies): django-stubs-ext 移到主依赖，支撑运行时泛型下标

**问题**：Django 6.1 移除运行时泛型下标支持，`ModelForm[Lawyer]` 等写法在生产 `--no-dev` 环境（未安装 dev 依赖）会崩溃。

**修复**：将 `django-stubs-ext` 从 dev 依赖移到主依赖，通过其运行时补丁为 `ModelForm`/`ModelAdmin`/`Field` 等提供 `__class_getitem__`。

### 新功能

#### feat(documents): 新增佛山法院送达地址确认书模板并同步默认模板配置

新增 `佛山法院送达地址确认书.docx`（适用禅城、佛山中院、三水、南海、顺德、高明 6 家法院），删除原禅城版；`complete_defaults.json` 同步数据库最新配置——民商事合同 `contract_types` 增加 `administrative`、申请执行文件夹 `case_types` 收敛为 `civil`、绑定关系由 36 条调整为 38 条（佛山版模板绑定民事一审起诉/二审答辩/二审上诉）。

#### feat(admin): 文书模板适用机构支持搜索结果全选与单项勾选

`institution_tags` 组件支持在适用机构搜索列表中全选/取消全选当前搜索结果，并保留单项勾选能力。
