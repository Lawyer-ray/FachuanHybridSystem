#### 优化：pydantic-ai 2.0 适配代码

pydantic-ai 2.0 的 MCP API 有 breaking change，适配以下变更：

**definitions.py**（`apps/workbench/agents/definitions.py`）

- `MCPServerStdio` 被 `MCPToolset` + `StdioTransport` + `fastmcp.Client` 替代
- fastmcp 成为 pydantic-ai 核心依赖，不再需要 `[mcp]` extra
- `tool_prefix` / `timeout` 参数迁移到 `StdioTransport`（cwd）和 `Client`（timeout）

**chat_service.py**（`apps/workbench/services/chat_service.py`）

- `FunctionToolResultEvent.result` 属性移除：`tool_call_id` 直接在 event 上，`tool_name` 从 `event.part` 获取
- `run.result.usage()` 从方法变为属性

#### 优化：ruff 0.16 兼容修复

`apps/doc_convert/services/znszj_loader.py` 的类型注解 `ZnszjClientProtocol | None | bool` 中 `None` 不在末尾，违反 ruff 0.16 新规则，修正为 `ZnszjClientProtocol | bool | None`。

### Skills

#### 新功能：合同自动编号 AI 辅助模式

新增 `analyze_document()` 和 `apply_numbering_map()` 两个函数，实现三步流程：

1. `--analyze` 提取段落结构 JSON（索引/文本/前缀/是否标题/是否签名）
2. AI 根据语义理解分配层级（0/1/2/3）
3. `--apply-map` 应用 AI 层级映射生成 Word 自动编号

适用于正则难以处理的复杂编号格式，如「1、既是子标题又是内容段落」的场景。
