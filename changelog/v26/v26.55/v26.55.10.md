### 1. Skills：案件处理工作流目录名回退为中文

#### 背景

v26.55.9 在按 Agent Skills Specification 规范化改造时，将 `skills/案件处理/` 下两个 skill 的目录名由中文改为 kebab-case 英文：

- `文件识别/` → `file-recognition/`
- `按标题拆分/` → `markdown-splitter/`

这违反了 `skills/CLAUDE.md` 的命名规范——「Skill 目录：中文，动词+名词」，且与同仓库 `合同处理/` 下已有的中文 skill 目录（`doc转docx/`、`合同自动编号/`）不一致。本次回退为中文目录名。

#### 修复内容

- **目录名回退**（`git mv`，保留文件历史）：
  - `skills/案件处理/file-recognition/` → `skills/案件处理/文件识别/`
  - `skills/案件处理/markdown-splitter/` → `skills/案件处理/按标题拆分/`
- **模块执行入口回退**：
  - `python -m skills.案件处理.file-recognition.scripts` → `python -m skills.案件处理.文件识别.scripts`
  - `python -m skills.案件处理.markdown-splitter.scripts` → `python -m skills.案件处理.按标题拆分.scripts`
- **同步更新所有文档和代码中的模块路径引用**：README / SKILL / references / scripts docstring / config.example
- **`SKILL.md` frontmatter 的 `name` 字段保留英文**（`name: file-recognition` / `name: markdown-splitter`），与 `合同审查` 的 `name: contract-review` 一致——frontmatter `name` 是 Agent Skills 规范的英文标识符，与目录名（中文，用于人类阅读）分离

#### 顺带修正

- `skills/README.md` 中案件处理 Skills 数量 1 → 2（v26.55.9 漏更新）
- `skills/README.md` 中两个 skill 的版本号 1.0.0 → 1.1.1（同步到当前 CHANGELOG 版本）
- `skills/README.md` 中模块路径 `python -m skills.案件处理.文件识别` → `python -m skills.案件处理.文件识别.scripts`（v26.55.9 漏写 `.scripts`）
- `skills/案件处理/README.md` 中 Skills 列表版本号 1.1.0 → 1.1.1
