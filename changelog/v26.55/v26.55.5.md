# v26.55.5

## 归档智能化：同步后自动检测监督卡 + 学习真实归档习惯

---

### 后端

#### 新功能：从合同文件夹同步后自动检测监督卡

实现「同步→检测监督卡」一键串联，用户点「确认导入」后自动触发监督卡 OCR 检测与剥离，无需再手动点「检测监督卡」按钮。

- 在 `ContractFolderScanService.confirm_import` 导入完成后调用 `_auto_detect_supervision_card`
- 复用现有 `SupervisionCardExtractor.detect_and_extract(contract)` 逻辑（OCR 最后 2 页 + 关键词匹配 + 提取为独立 PDF）
- OCR 失败不影响导入结果（异常被吞，导入数据随外层事务正常提交）
- 返回值新增 `supervision_card_detection` 字段（triggered/found/extracted_count/detail）
- 幂等性：`_save_extracted_card` 会查重 `archive_item_code`，重复调用安全

#### 优化：学习机制限定只从已归档合同学习

`learn_from_archived_materials` 查询加 `.filter(contract__status='archived')`，只从稳定数据学习，避免学到在办合同中用户还在整理的临时归类。

#### 优化：收紧学习关键词白名单

移除过短或过于通用的关键词（"通知"、"受理"、"归档"、"案卷"、"封面"、"目录"、"登记"、"小结"、"办案"、"意见"等），这些词作为子串会误命中大量不相关文件名。

新增更具体的关键词：通知书、受理通知、保全申请、财产保全、证据清单、调查笔录、会见笔录、庭审笔录、案卷封面、结案归档、案卷目录、监督卡、服务质量监督卡、委托合同、委托代理合同、法律意见书、发票、收费凭证、保全费等。

#### 优化：DB 学习规则按 hit_count 降序排序

`_get_db_learned_rules` 查询加 `.order_by("-hit_count")`，高频规则优先匹配，避免低频规则抢先命中导致误分类。

#### 优化：歧义关键词消歧

同一关键词映射到多个 code 时，检查是否可按 `category` 字段消歧：如果不同 code 对应不同 category 且数量一致，不标记为歧义，允许学习。

#### 新功能：学习回测准确率报告

学习前后各跑一次全量回测，输出准确率对比：
- `accuracy_before`：学习前当前规则对已归档材料的分类准确率
- `accuracy_after`：学习后新规则的分类准确率
- `total_materials`：参与学习的材料总数

用户可通过准确率变化判断学习是否有效。

#### 优化：归档分类单元测试

- 新增 `TestAutoDetectSupervisionCard`：3 个测试覆盖监督卡自动检测（检测到/未检测到/异常）
- 新增 `test_accuracy_report_fields`：验证学习回测字段
- 修复 `test_ambiguous_keywords_detected`：补充 ArchiveClassificationRule mock（修复 pre-existing 失败）
- 更新 `test_compound_keyword_kept`：反映收紧白名单后的关键词提取行为
