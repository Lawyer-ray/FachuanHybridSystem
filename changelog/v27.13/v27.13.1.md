# v27.13.1 · 案件编辑页「一张网ID + 同步」

案件编辑页（`/admin/cases/case/<id>/change/`）新增「一张网ID」字段与「同步」按钮：填好一张网
案件标识后点同步，用**当前登录人自己**的一张网账号登录，读取该案详情，把案号与审判组织成员
回填到本系统。

## 后端

### 新功能

- `cases.Case` 新增 `yz_wid`（「一张网ID」，`varchar(64)`，索引；含 `HistoricalCase` 影子列）。
  迁移 `cases/0042_case_yz_wid.py`（纯新增列，无数据改动）。
- 新增插件模块 `plugins/court_automation/case_sync/`，承载**除字段外的全部功能**：

  | 文件 | 职责 |
  |---|---|
  | `client.py` | 复用 `plugins.court_automation.login` 登录（HTTP+SM2 优先，失败回退 Playwright）、调一张网案件详情接口、字段归一化 |
  | `service.py` | 幂等落库：案号 → `CaseNumber`，审判组织成员 → `contacts.CaseContact` |
  | `admin_integration.py` | admin 端点 `<id>/yizhangwang-sync/`、权限校验、模板上下文、提示文案 |
  | `static/court_automation/{js,css}/yizhangwang_sync.*` | 「同步」「打开一张网」按钮与提示条 |

- 宿主 `apps/cases` 侧只有三处薄接线：`CaseAdmin.get_urls()` 追加插件端点、
  `changeform_view()` 注入插件上下文、`change_form.html` 用一个
  `{% if has_yizhangwang_plugin %}` 引用插件静态资源。**插件缺失时整块功能退化为原样**，
  案件编辑页其余部分不受影响。
- `settings.STATICFILES_DIRS` 在插件可用时注册 `plugins/court_automation/static`
  （与既有 `_TEMPLATE_DIRS` 同思路，未装插件不注册以免 Django W004）。

### 对接事实（实测，勿凭猜测改动）

- 案件详情：`GET https://zxfw.court.gov.cn/yzw/yzw-zxfw-ajfw/api/v1/ajxq?ajbh=<ajbh>`
- 请求头 `Authorization: <裸 token>`——**不加 `Bearer` 前缀**，加了返回 401。
- 响应 `data`：`ajVO`（`ah` 案号、`ayms`/`laaymc` 案由、`fydmTranslateText` 法院、
  `cbsptTranslateText` 审判庭、`ajmc` 案名）、`spzzcyList[]`（`xm` 姓名 +
  `jsTranslateText` 角色：审判员/书记员/法官助理/人民陪审员）、`sscyrList`/`ssdlrList`。
- 注：`ajxq` 的参数名是 `ajbh`；传 `bh` 会得到 `code=200, message=案件不存在`（易误判）。

### 回填口径

- 案号：按 `CaseNumber.number` 判重后**新增**，不覆盖已有案号的裁判文书文件与执行参数。
- 审判组织成员：按 (姓名, 角色) 判重后新增到 `CaseContact`，`note` 标记「由一张网同步」。
  「人民陪审员」归入 `judge`（系统无独立枚举）。
- 案由 / 案件名称：**仅在本系统为空时补全**，不覆盖用户已填内容。
- 全部幂等，可重复点同步。

### 安全

- 只使用**当前登录律师本人**的 `AccountCredential(site_name="一张网")`，不存在借用他人账号
  越权查案的可能；未登记账号时给出明确中文提示而不是静默失败。
- 端点走 `admin_site.admin_view` + `has_change_permission` + `CaseAccessPolicy` 行级校验，
  与案件 admin 其它自定义端点同口径。
- `httpx` 请求设 `trust_env=False`，避免本机代理把法院域名代理出去导致超时。

### 迁移

`cases/0042_case_yz_wid.py` 需执行 `manage.py migrate cases` 后才生效（未迁移时 `Case` 查询会因
缺列报 `UndefinedColumn`）。
