# v27.15.1 · 非诉页卡片间距重排（去「三层套娃」）

## 前端

### 优化

#### 非诉详情页（专项 / 跨境 / 常法）卡片间距与边框层次

用户实测反馈：「非诉页面 UI 有点诡异，每个卡片之间很紧凑，没有合适的边距」。
拉开一量，问题不在**卡与卡之间**（那一直是 18px 栅格），而在**卡内部又套了两三层边框**：

| 层次 | 原状 | 症状 |
|---|---|---|
| 左栏卡片 | `Card` 自带边框 + 阴影，逐张通栏堆叠 | 卡间 18px 正常，但卡一变高，观感就是「一整块密排」 |
| 卡内列表 | 列表再画一整圈 `border` + 每行 `divide-y` | 与卡片边框形成同心矩形，行与行之间只剩一条 1px 线 |
| 卡内条目 | 条目再画一圈 `border`（校验项 / 风险行 / 执行块） | 三层边框相邻，中间白缝只剩 6px，被读成「挤」 |
| 模板行 / 执行卡 | 行内 `py-1.5`、卡中卡 `px-[18px] py-[15px]` | 行高过矮，与外围 15px 内边距不成比例 |

改法（只动视觉，不动任何交互与状态机）：

- **卡与卡**：统一 18px。`CrossBorderViews` 由 `mt-4`(16) 改为 `mt-[18px]`，与
  `DealDocLayout` 的 `space-y-[18px]` 同口径，不再出现 16/18 两种节奏。
- **卡内列表**：外框保留一圈，**行改成 `border-b` + `last:border-b-0`**，行高 `py-2 → py-2.5`。
  原来 `dark:divide-y` 与 `rounded + border` 叠加时，首尾行会被外框和内部分隔线夹出双线。
- **卡内条目**：`Inset`（专项共用内嵌层）默认**不画边框**，只留 `bg-secondary/35` 底色，
  需要真边框的场合显式 `framed`（如客户确认记录里的信息块）；
  `NonLitActionCard` 里的 `InsetBlock` 同步改为无边框 + `bg-secondary/35`。
- **三层套娃的直接拆除**：
  - 推进前置校验：条目不再各画一圈边框，改用**左侧 3px 色条**（绿=通过 / 黄=未通过）分档，
    底色只在未通过项上淡染；
  - 风险登记表：整表一层外框，高风险行改用**左侧红色条**标记，不再给行套红边；
  - 卡片内嵌的「执行卡」（`NonLitActionCard`）：`border-0 + border-l-[3px] + shadow-none`，
    待执行态 `bg-secondary/30`——
    它本身就是卡里的一块，再画一圈边框+阴影就成了「卡中卡」；
  - 跨境工作台的最外层是**容器卡**（内含 7 张子卡），改为 `border-0 bg-transparent shadow-none`。
- **行高与留白**：模板行 `py-1.5 → py-2`（去掉边框改底色块）；甘特阶段行 `py-[3px] → py-[5px]`；
  卡内「动作卡列表」与后续区块统一 `mt-3 → mt-3.5`；块标题 `mb-1.5 → mb-2`。
- 校验项里的说明文字（`r.detail`）加 `min-w-0 truncate` + `title`，窄栏换行不再把
  「未通过」胶囊挤扁。

改动文件（均在 `frontend/src/features/workbench/components/deal-detail/`）：

```
nonlit-action-card.tsx                    执行卡：卡中卡 → 左侧色条 + 浅底
nonlit-workbench.tsx                      专项 / 跨境 / 常法：区块间距、容器卡去边框、模板行
nonlit/special/special-bits.tsx           Inset 默认无边框（+framed 逃生口）
nonlit/special/special-phase-board.tsx    校验项 / 阶段清单 / 交付物清单
nonlit/special/special-risk-card.tsx      风险登记表 / 客户确认记录
nonlit/special/special-gantt-card.tsx     甘特行高与图例间距
nonlit/crossborder/CrossBorderViews.tsx   mt-4 → mt-[18px]
```

验证：`npx tsc -b --noEmit`、`npx eslint src/features/workbench/components/deal-detail` 均通过；

六块，卡间距一致、无同心边框叠加。
