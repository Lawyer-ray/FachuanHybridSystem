# v27.11.6

## 前端

#### 新功能

- **收费节重排：钱与票两条线分开**（`RailFees.tsx`，自 `RailArchive.tsx` 拆出）：已收/已开票/未收改三格统计条（0 也显式给出，未收不可知时降为「—」）；「收款」小节逐笔记钱（金额 + 开票状态徽标：未开票灰 / 部分开票黄 / 已开票绿 + 备注）；「发票」小节列识别归档后的发票（重命名文件名 + 价税合计 + 待核销徽标），空态一键上传。先收费后开票、先开票后收费两条路径在节头并列（＋ 记收款 / ＋ 传发票），整节仍可拖票直达。
- **一键复制发票文件**（`PaymentInvoiceZone.tsx` 的 `CopyInvoiceFileButton`，收费节 / 记收款弹窗 / 传发票弹窗的发票行共用）：后端 NSPasteboard 落板后微信对话框 ⌘V 直接粘出**重命名后**的文件；环境不支持时降级复制文件名并如实提示（与法院短信文书同一套链路）。

#### 优化

- 记收款弹窗与传发票弹窗的发票行：复制按钮从「复制文件名」升级为「复制文件本体」。

## 后端

#### 新功能

- **发票重命名改用合同名称**（`invoice_file_service.py`）：`发票（{合同/案件名称}）_YYYYMMDD开具.pdf`（此前用销售方名）——律师按案找票，合同名才是检索键；名称按 UTF-8 字节截断（整名不超 macOS 255 字节上限），合同名缺失退销售方再退「发票」。media 仓库存 UUID 原名不变，合同文件夹镜像与新展示名同步更新。
- **`POST /finance/invoices/{id}/copy-to-clipboard`**（`contractpayment_enhance_api.py`）：把发票以重命名后的文件名复制到 macOS 系统剪贴板（临时目录落盘后写 NSPasteboard file-url，同 Finder ⌘C）。落板文件留存到粘贴之后，只清扫 24h 前的旧副本；非 macOS / 无 pyobjc 返回 `unsupported`，前端降级。行级 ACL 与收款口径一致。

#### 测试

- 命名规范测试改为合同名称口径（含超长案名字节截断断言）；新增复制端点两条集成测试（重命名落板 / 非 macOS unsupported）。
- 结构门禁清偿：`_payment_invoice_state` 的 ORM 查询从 API 层下沉 Service（`API 层 Model.objects` 棘轮归零恢复通过）；`invoice_file_service` / `payment_sms_parser` 的 `@staticmethod` 纯函数下沉模块级（Service 层棘轮 29→24，余 24 条为分支既有债待另行清偿）。
