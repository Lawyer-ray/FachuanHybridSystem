# v27.11.10 前端 · 账号绑定页升级为设置页 + 后端/Django-Q/LLM 三卡系统状态

## 前端

### 新功能

- **`/settings/bindings` 升级为设置页 `/settings`**：原页面只承载账号绑定，现拆成两个分区——「系统状态」在上、「账号绑定」在下，一屏看完"系统活不活 + 我的账号绑了啥"。旧路径 302 到 `/settings` 并**保留 query**：绑定回调的 `bound=<provider>` 标记由绑定面板消费，丢了就不弹绑定成功提示。
- **系统状态三卡片**（`SystemStatus`）：

  | 卡片 | 数据源 | 判定 |
  |---|---|---|
  | 后端服务 | 一次鉴权 GET 的往返耗时（`organization/me` 探针） | 正常绿；>1000ms 黄牌但**仍表述为在线**（局域网正常两位数，过千多半是后端假死或网络异常，不直接判死）；请求失败才红「无法连接」 |
  | Django-Q 任务队列 | 新增 `GET /task-queue/cluster-status` | 心跳 0 = 「无集群心跳」红；1 = 运行中绿；>1 = 「疑似僵尸集群 ×N」黄牌并给出抢队列告警；`clusters=null`（redis 探测失败）= 「无法探测」灰，**不回退成 0** |
  | LLM 网关 | `llm/models` + `agent/usage` + `llm/test-connection` | 模型面数量为状态；展示近 1 天 AI 任务次数/成功率/平均耗时；可下拉选模型手动测连通性 |

- **三卡完全独立**：各自 `useQuery`，任一张失败（含后端探针整机不可达）不拖垮另两张，只在该卡内显示错误文案。
- **「刷新」统一 invalidate `['settings']` 前缀**：一次点击三卡一起重取，不用逐个点。
- 数据只在页面打开时读取，**不做后台轮询**——状态页不该自己成为负载源。

### 优化

- **`BindingsPage` → `BindingsPanel` 重命名**：它不再是整页，只是设置页里的一个分区，名字对齐实际职责。
- `social-api.ts` 的 `createBindSession` 默认 redirect 随页面迁移改为 `/settings`；回调域 `withQuery` 注释同步更新。
- `BindingsPanel` / `SettingsPage` 均走 lazy 出口（同 `features/auth` 的理由：静态 re-export 会把整域钉进首屏 chunk）。

### 测试

- 新增 `SystemStatus.dom.test.tsx`（14 例）：三卡齐出与正常态文案、后端慢响应判黄牌而非错误、探针失败时另两卡照常渲染（独立性契约）、Django-Q 三态判定（0 心跳 / 僵尸 ×3 / 无法探测）、`clusters=null` **不被误显示成「0 个」**、LLM 无模型时下拉与按钮双禁用、`test-connection` 成功/失败两分支文案、刷新 invalidate 前缀契约。
- `App.dom.test.tsx` / `AppNavbar.dom.test.tsx` 跟进路由与入口改动。

## 后端

### 新功能

- **`GET /task-queue/cluster-status`**（`apps/core/api/task_queue_api.py` + `apps/core/tasking/task_queue_query.py::cluster_status`）：返回集群心跳数 / 队列深度 / 今日成功失败计数 / 最近成功失败时间 / broker 错误摘要。

  与同文件的其他任务明细端点不同，这里**不做** `ensure_admin_request`：返回的是纯聚合数字，不含任务载荷；律师在设置页看系统状态也需要它，路由层挂的 `JWTOrSessionAuth` 已足够。管理员身份校验仍由 `llm/test-connection` 等敏感端点保留。

  `clusters` 由 redis 心跳键按**集群名去重**得出（键形如 `django_q:<集群名>:cluster:<pid>`，同一集群多进程只算一个名字）；非 redis broker 或探测失败时为 `None` 而非 `0`——前端据此区分"探测不到"和"确实没集群在跑"。

### 测试

- `test_tasking_query_services.py::TestClusterStatus`（4 例）：非 redis broker 返回 None 且不算错误、redis 探活异常降级为 None、心跳键按集群名去重、今日成败计数与最近运行时间取值。
