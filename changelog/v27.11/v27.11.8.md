# v27.11.8 前端 · AI 助手并排布局自适应修复

## 前端

### 修复

- **AI 助手不再挤坏页面布局**（全站性问题）：此前所有页面的多栏/栅格断点都写在**视口**上（`xl:` / `md:` / `max-[1200px]:`），而 AI 助手面板（默认 600px）并排让位时吃掉的是**容器净宽**、悬浮时直接盖住右侧内容——视口断点两者都感知不到，表现为日历挤成窄条、复审三栏挤成缝、阅读器右栏被盖。现全部改为**容器查询**（Tailwind v4 `@container` + `@min-[]:` / `@max-[]:`，阈值由旧视口断点扣除页边距换算）：
  - 首页（HomePage）：双栏 `minmax(0,1fr)_340px` 改按 main 净宽 ≥1200 生效，助手让位后自动回落单栏（日历占满、右栏下移）；
  - 首页快捷工具坞（ToolDock）：四卡并排改按左栏净宽（≥1100 四列 / ≥560 两列），不再在窄栏里硬塞四张卡；
  - 首页日历（CalendarPanel）：每格事件行数上限（3/4/5）从视口 matchMedia 改为面板实测宽度驱动；
  - 合同复审工作台（ReviewWorkbenchPage）：三栏 `290px_1fr_320px` 改按容器净宽分级回落（≥1150 三栏 / ≥850 两栏 / 只留画布）——本路由宽屏恒并排，原先必挤；
  - 非诉详情页（NonLitDetailPage）：宽屏右栏加宽断点（1900/2400）改按容器净宽（1760/2200）。
- **AI 助手宽屏默认并排**（AppShell）：`copilot:dock` 偏好默认值从「悬浮覆盖」翻转为「并排让位」——悬浮会盖住内容且页面无从自适应，并排后配合容器查询页面按净宽重排；已显式保存过偏好的用户不受影响，面板头部切换按钮照旧可切回悬浮。
- **材料预处理阅读器与 AI 助手同屏**：
  - 阅读器是 `fixed inset-0` 全屏层、不吃页面 padding，并排时右半被面板盖住。现通过 `--copilot-docked-w` CSS 变量（AppShell 并排时写入）把阅读器右缘收进来，阅读与 AI 同屏对照；
  - 阅读器窄屏形态（≤1100 抽屉化）、工具栏单行/双行、侧栏宽度等断点全部改按**阅读器自身净宽**（`FixedReader` 建 `@container` + 实测宽度），并排让位后自动切抽屉布局；
  - 窄屏抽屉与遮罩从 `fixed`（定位到视口，右抽屉会画到助手底下）改为 `absolute`（相对阅读器三栏主体行）。

### 优化

- `useElementWidth` 从 material-prep 域提权到全局 `src/hooks/`（首页与材料预处理两域共用的容器净宽测量），并加 jsdom 兜底：无 `ResizeObserver` 时跳过观察、保留挂载瞬间测量，组件测试不必逐文件 stub。

### 测试

- Reader.dom.test：窄屏 mock 从 `use-media`（matchMedia）改为 `use-element-width`（实测宽度），遮罩断言随 `fixed→absolute` 同步；
- 其余 2319 例全量通过；构建产物确认容器查询 at-rule 全部生成（`@container (width>=…)` / `not (width>=…)`）。
