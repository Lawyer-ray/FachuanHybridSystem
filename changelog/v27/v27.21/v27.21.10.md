## 三条设计决定

### 1. 三个字段提为代码常量，不进 SystemConfig

用户拍板：平台地址、挂载清单、并发上限是**稳定常量**，不该占配置行、也不该要人点初始化才有。

```python
# apps/core/services/yuandian_settings.py
YUANDIAN_MCP_BASE_URL = "https://open.chineselaw.com"
YUANDIAN_MCP_SERVERS = ("law", "case", "company", "securities")
#                        ↑ hallucination 仅 VIP 可用，故不列
YUANDIAN_CONCURRENCY_PER_KEY = 2
```

`_service_configs.py` 里那三条默认项已删，元典只剩 **1 条**：`YUANDIAN_API_KEYS`（`is_secret=True`、留在 `_MULTI_KEY_CONFIGS`）。
代价：想只挂 law/case 就得改代码发版（已写进常量注释）。收益：启动即可用，无初始化步骤，无孤儿配置行。

### 2. key 只以 env 占位落盘

`mcp.json` 里写 `"Authorization": "Bearer ${FACHUAN_YUANDIAN_API_KEY}"`，真值由 `pool.py` 注入 pi 子进程 env
（复用 pi 对 mcp.json header 的 env 展开，我们自己的 `${FACHUAN_USER_TOKEN}` 就是同一机制）。

真库端到端实测（真实配置生成后读回）：

```
mcpServers = ['fachuan','yuandian-law','yuandian-case','yuandian-company','yuandian-securities']
元典 server 数 = 4      hallucination 出现 = False
真实 key 出现在文件里 = False      占位符出现次数 = 4
```

没配 key 时**不注入空串**（`Bearer ` 只会换来看不懂的 401），而是整个 env 变量缺席、元典 server 也不挂。

### 3. `type` 用我们自己的取值，不照抄官方

官方示例写 `"type": "http"`，但我们自己的 server 在 pi 上验证过的是 `"type": "streamable-http"`。
**以验证过的为准**——照抄未验证的形状，最可能的失败是「工具全不出现且不报错」。
