# v27.0.3

新一代前端依赖大版本升级（含 PDF 渲染引擎 4→6 迁移），并补齐本地 CI 依赖安全审计白名单。

## 前端

#### 依赖变更

- 升级 9 个依赖至最新版：`@tanstack/react-query` 5.103、`lucide-react` 1.46、`pdfjs-dist` 6.3、`react-router` 8.4、`eslint` 10.10 / `@eslint/js` 10、`eslint-plugin-react-refresh` 0.5.7、`globals` 17.12、`vitest` 5.0
- `typescript` 保持 6.0.3：`typescript-eslint`（最新 8.70）尚不支持 TS 7（peer 上限 `<6.1.0`），暂缓升级留待生态跟进

#### 修复

- `pdfjs-dist` 4→6 迁移：`PDFDocumentProxy.destroy` 移除，改为由 `PDFDocumentLoadingTask.destroy` 释放缓存；`page.render` 参数由 `canvasContext` 改为 `canvas`
- 清理升级后 ESlint 10 不再需要的两处冗余 `eslint-disable` 指令

## 后端

#### 构建 / CI

- 本地 CI `scripts/ci-local.sh` 的 pip-audit 白名单补齐远端 CI 已忽略的 4 个 CVE（CVE-2026-48990 / 49452 / 49477 / 49476），避免本地 push 误拦
- 保留本地 TRAE 环境特有的 2 个 PYSEC 忽略项（PYSEC-2026-3447 / 3721）并追加注释说明，防止误删导致本地 push 失败
