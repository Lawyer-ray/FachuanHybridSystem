# v27.0.5

材料预处理增强：材料包标题支持重命名，委托人 / 对方当事人 / 受益人字段支持从当事人库模糊检索、标签戳选填报，并补齐精简检索端点兜底证件序列化缺陷。

## 前端

#### 新增

- 材料包标题可重命名：列表页右键菜单新增「重命名材料包」、阅读器顶栏标题旁新增铅笔按钮，共用 `RenamePackDialog`；保存后同步更新已打开阅读器的标题，并失效材料包列表缓存
- 新增 `PartyPicker` 标签戳选组件：委托人 / 对方当事人 / 受益人字段输入即从客户库模糊检索，下拉候选选中生成可删除标签，多个以顿号分隔，支持回车将自由文本直接填入
- 材料预处理信息字段新增「受益人」

#### 修复

- 当事人检索改调精简端点 `/api/v1/client/parties/search`，规避沿用 `/clients` 完整 `ClientOut` 时证件档案为空导致序列化 500
- 检索范围按我方 / 对方限定：委托人为我方当事人，对方当事人为对方，受益人归入我方当事人范围

## 后端

#### 新增

- 当事人检索精简端点 `GET /api/v1/client/parties/search`：按关键字模糊检索，`is_our_client` 控制我方 / 对方范围过滤，仅返回检索填报所需的 `id / name / phone / is_our_client`，不携带证件文档
- 材料包重命名接口 `PUT /api/v1/inbox/messages/{message_id}`：名称去除首尾空白后非空校验，超长截断至 512，落库并记录日志
- 放开证件 `file_path` 可为空：`ClientIdentityDocOut` / `IdentityDocDetailOut` / `PropertyClueAttachmentOut` 由 `str` 改为 `str | None`，支撑无证件档案的当事人检索

#### 测试

- 新增 `test_party_search`：覆盖精简字段返回、带证件档案时不序列化证件、我方 / 对方范围过滤
- `test_message_hub_api` 适配重命名接口，并为测试账号凭据补 bandit 密钥 allowlist 注释
