# v27.0.2

新一代前端（`frontend/`）从 `frontend_2026` 迁移并全量落地，材料预处理进入可用闭环。

## 前端

#### 新增

- 材料预处理全新前端（React 19 + Tailwind v4）：材料包列表、详情拆分、段归类、OCR 框选取字完整闭环
- 详情页加路由 `/material-prep/:id`，支持刷新 / 分享 / 直达指定材料包
- 阅读器按原型 sgrid 模型还原多列并排布局：1/2/3 列自适应，窄屏自动回落单列，页行在画布内恒居中
- 详情页右键菜单删除所选页（从拆分草稿移除引用、清理空段）
- 列表页右键菜单删除材料包（新增后端删除接口支撑），统一右键基建
- 统一右键菜单组件 `context-menu`（Radix 封装）与破坏性操作二次确认约定（AlertDialog）
- 登录页改为极简居中设计，去除「法」字 logo，文案定位通用办案平台
- 新一代前端目录 `frontend_2027` 更名为 `frontend` 并纳入版本控制

#### 修复

- 阅读器打开 / 退出补淡入、淡出过渡动画
- 修复键盘高亮框错位（绝对定位脱锚），补充材料包卡片悬停动画
- 修复多列窄屏下布局挤压与列数切换失效
- 修复空格选页误触（选区按钮聚焦残留）
- 修复多列时页行横向截断 / 偏移，改为恒居中且不产生多余横向滚动条
- 退出登录后跳转回到 `/login`
- 材料包 API 基础路径修正为走 vite 代理

#### 优化

- 拆分阅读器巨石组件，按 Feature 约定目录结构与文件规模阈值落地
- 对齐原型还原度细节：段头条 / 阅读器顶栏 / 选页高亮 / 浅灰底 / 取字提示横条 / 左右栏白底

#### 构建 / CI

- 前端 CI 触发路径从 `frontend_2026` 迁移到新一代 `frontend/`，移除 skip 条件
- `make frontend` 改用新一代目录并迁移到 5090 端口

#### 依赖变更

- 新增 `@radix-ui/react-context-menu`（统一右键菜单组件基础）

#### 文档

- 新增新一代前端正式 README，替换旧版

## 后端

#### 新增

- 收件箱材料包删除接口 `DELETE /api/v1/inbox/messages/{id}`：先按暂存 `local_path` 清理附件物理文件，再删除消息记录，避免遗留垃圾文件

#### 其他

- CORS 白名单补充注释说明：开启 `allow_lan` 时以 `.env` 配置为准
