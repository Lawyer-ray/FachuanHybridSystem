# v27.0.6

系统配置后台精简与消息来源 admin 文案清理：移除「同步环境变量」与「增加系统配置」两个低价值入口、清理消息来源 admin 冗余说明文案，手动上传消息在后台可直接查看上传人。

## 前端

本次无前端改动。

## 后端

#### 新增

- message_hub admin：手动上传消息新增「上传人」展示——列表新增上传人列、详情页只读展示上传人、侧边过滤支持按上传人筛选，并补 `list_select_related` 避免列表 N+1 查询（上传人数据此前已随上传自动落库，仅后台未展示）

#### 修复

- message_hub：移除消息来源 admin 的冗余说明文案——来源表单 `help_text`、发件人过滤 fieldset 的 `description`、IMAP 主机 / 账号字段的 `help_text`（另新增 0012 / 0013 迁移）
- core：修复 Django 6.1 下日期时间控件在 admin 表单中竖排堆叠的问题（`base_site.html` 补充样式）

#### 优化

- core admin：隐藏系统配置的「增加 系统配置」入口（去掉默认 add 按钮渲染）；系统配置项由代码 / 平台管理页定义，避免手敲无消费方的无效 key。保留 `has_add_permission`，`/add/` 直连仍可访问

#### 移除

- core admin：移除「同步环境变量」按钮及 `sync_env_view`、`_env_mappings.py` 死代码——该类环境变量映射因配置已全面迁往 SystemConfig / LLMProvider 而无命中对象，保留独立的 `init_system_config --sync-env` 命令行功能
