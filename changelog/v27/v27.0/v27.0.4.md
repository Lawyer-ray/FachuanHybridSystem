# v27.0.4

修复本地 CI 前端目录假绿并优化 pre-push 钩子的资源消耗：按改动范围裁剪检查、依赖审计加网络门控、纯删除操作跳过本地检查。

## 后端

#### 构建 / CI

- `scripts/pre-push` 对纯删除操作（删除分支 / tag）跳过本地 CI：删除时 pre-push 输入中本地 sha 为全 0，无新代码可检查，避免白跑 lint + typecheck
- 修复本地 CI 前端假绿：`scripts/ci-local.sh` 的 `FRONTEND_DIR` 由已废弃的 `frontend_2026` 改为 `frontend/`，本地前端检查恢复真实覆盖新一代前端（此前扫描本地残留旧目录，属无效检查）
- `ci-local.sh` 新增 `--auto` 模式：按 `BASE_MERGE..HEAD` 改动范围自动只跑后端或前端，`pre-push` 默认启用，避免每次 push 双侧全跑浪费
- `ci-local.sh` pip-audit 增加依赖文件变更门控（无 `pyproject.toml` / `uv.lock` / `requirements` 改动即跳过网络扫描），网络抖动失败自动重试一次，消除误伤
