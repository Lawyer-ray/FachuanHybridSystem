## 后端

#### 修复

- **湖北免账号爬虫异步下载静默失败（P0）**：`hbfy_scraper._atry_expect_download` 漏写 `await download_info.value`（playwright async API 惯用法），运行时必抛 AttributeError 且被 `except Exception` 吞掉，表现为该异步下载路径永远失败且无日志
- `contract_generator` 的 `GenerationResult.file_path` 传 Path 对象而 dataclass 声明 `str | None`，补 `str()` 转换
- `_extract_primary_supervising_authority_id` 显式 None 前置判断（原依赖 `int(None)` 抛 TypeError 走 except 分支）
- 保全询价任务改传 `TokenServiceAdapter`（`ITokenService` 协议的正规实现）——原传同步 `TokenService`，协议签名（async 单参）与实现（同步双参）长期脱钩，类型契约失效
- 本批自身引入的 `NameError`（`CaseImportPayload` 在 TYPE_CHECKING 内导入，cast 改字符串形式），由全量单测捕获并修复

#### 优化（类型清理，均零行为变化）

- **自定义 Path 类型修复**：`apps/core/utils/path.py` 的动态基类对 mypy 是 Any、污染全部下游——增加 `TYPE_CHECKING` 静态基类分支（运行时不变），联动清理 9 处下游失效 `type: ignore`
- **法院文书爬虫双态收窄（132 个错误）**：`BaseScraper.page` 声明为 sync/async Page 联合类型导致 5 个爬虫文件（jysd/gdems/sfdw/hbfy/main）所有 page 调用互斥报错——新增 `as_sync_page`/`as_async_page`/`as_sync_context` 收窄 helper，方法内先收窄为局部变量再使用
- **models 字段注解反模式批（142 处）**：`xxx: str = models.CharField(...)` 的实例属性注解与 django-stubs 的 descriptor 类型冲突（batch_printing/document_recognition/pdf_splitting/invoice_recognition 四个 app），删注解即消；evidence_admin 等 Admin 配置属性（`: tuple[Any, ...] =` / `: ClassVar =`）同根因 12 处
- **material_classification 一处 dict 注解错误消 62 个**：`_ARCHIVE_FOLDER_KEYWORD_RULES` 声明 `dict[str, dict[str, list[str]]]` 但字面量与消费方均按 `str` 使用
- **chat_records_api**：新增 `_request_user` helper 统一 11 处 `getattr(request, "user", None)` 的用户提取（router 已挂认证，cast 收窄）
- **协议与签名对齐**：`IContractFolderBindingService` 补 `get_binding`/`_resolve_subdir_path`；`build_context` 放宽为 `PlaceholderContextData | dict` 联合（运行时本接受任意 dict）；`BindingResult.success_result` 的 `case_id` 放宽为 `int | None`；express `get_actions` 对齐 Python 3.12 分支 stub 签名；`ContractSaveMixin` 用 TYPE_CHECKING 基类让 `super().save_model()` 可解析
- **长尾清理（Batch 8，114 个）**：15 处 `transaction.on_commit` 带默认参 lambda 统一 `ignore[misc]`（mypy 已知推断限制）；18 处 migrations RunPython 回调补参数注解；6 处 plugins ImportError 降级 stub 的 ignore 错误码修正；BaseScraper 双态 cast、guarantee sync/async 重复注解、source_gateway 补宿主方法声明、7 处 Batch 5 联动 unused-ignore 等散项
- 全批共清理 34 处失效 `# type: ignore` 注释
