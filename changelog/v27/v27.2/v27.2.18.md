# v27.2.18

第三轮最佳实践审查九批清偿收官（后端模型层/并发/异步 + 前端轮询竞态/a11y）+ OA filing JTN 真实环境热修四批 + GitHub 登录三件套（配置缓存 TTL 兜底、登录页重排、品牌升级）+ 许可证更换 PolyForm Noncommercial。

## 后端

#### 修复

- **并发与事务清偿**：update_payment 聚合移到 select_for_update 之后消除并发超付窗口；生成任务 metadata 读-改-写统一走行锁内重取（并发不再丢文件记录/错误日志）；法研反馈环 13 个 SystemConfig 键加锁（并发反馈不再互相覆盖权重）；证据清单/材料 order 取 Max+1 前先锁父对象；案件材料 replace/delete 补 atomic、物理文件删除统一 on_commit；归档 checklist 逐案 EXISTS 收敛、律师指派 bulk_create
- **模型层治理（16 个迁移，开发库已 migrate 验证）**：on_delete 语义修复（Case.contract→PROTECT、ReviewTask.user/FillRecord.template→SET_NULL、PropertyClue.client→PROTECT 配套删除守卫）；AccountCredential(lawyer,site_name,account) 与 Team(law_firm,team_type,name) 补唯一约束并 RunPython 清洗存量去重；冗余索引清理 22 处；__str__ 消除外键遍历 7 处（admin/日志 N+1）
- **异步线程模型清偿**：OCR 调用 thread_sensitive=False（PaddleOCR 120s 轮询不再队头阻塞共享线程）；云盘 OAuth 设备码轮询三份重复实现收敛为 provider 层一份 async 版（顺带修 Dropbox pending 误报 400、事件循环内直接 save() 两个隐藏 bug）；WebDAV 限速器加锁；LLM 模型探测改线程池并发 + 120s 总预算
- **openapi 导出缺斜杠**：196 条 router 路径回归 /api/v1/ 正确前缀
- **evidence 合并进度字段补 CheckConstraint + 完成态竞态加固**（迁移 documents/0020）
- **JTN 盖章/归档选案弹窗回填验证**：layui 弹窗 JS 静默 return 导致 Python 侧误判「已选中」，后续步骤被遮罩挡住——改为 JS 返回状态串 + 选后轮询验证弹窗真正移除
- **JTN 立案客户选择假阳性**：_try_select_client 在 layui cache 为空时静默 return 却被当成功——非 ok 改走建新客户流程；**发票半自动点错行**：结果表首行兜底改行级定位（按案号匹配行内申请入口，找不到即警告交人工、浏览器保持打开）
- **社交登录配置缓存 30s TTL 兜底**：信号失效只在写配置的进程内生效，脚本直写 SystemConfig 或多 worker 部署收不到信号，缓存非空永不重建（绑定页长期「该登录方式暂未开放」、只能重启）。ProviderRegistry 新增 ensure_configs_fresh，get_config/enabled_list/五处端点守卫统一走它

#### 优化

- **JTN 四脚本 Playwright 旁路迁入浏览器工厂**：新增手动会话 API 与 jtn profile，半自动模式浏览器生命周期纳入统一管理
- **OA 同步第 4 处 allow_async_unsafe 收敛统一桥接；爬虫 requests→httpx 栈统一**
- **JTN 半自动真实验证热修**：手动会话强制有头模式 + HTTP 链路补齐 trust_env=False

## 前端

#### 新功能

- **登录页重排**（参照 Supabase/Clerk 模式）：账密表单与按钮型社交登录同页（「或使用以下方式登录」分割线 + GitHub/Google 白底品牌按钮全宽堆叠）；飞书扫码独立「扫码登录」标签页（多扫码 Provider 时标签内次级切换）；无扫码方式时自适应单视图、无按钮方式时不渲染分割线。分组逻辑重构为 buildLoginMethodGroups，BRAND_MARKS 抽出共用

#### 修复

- **轮询竞态根治**：新增 use-poll-session（会话号守卫 + 挂起 sleep 主动唤醒 + 卸载自动失效），doc-parse/recognize/DocConverter 三个轮询 hook 全部迁移，新增 16 个竞态回归用例；五处 typeahead 每键即发请求改 250ms 防抖
- **错误态显性化**：首页日历区/统计句、收件箱卡、TodayCard、办案抽屉、四个历史弹窗——故障不再渲染成空数据假象；main.tsx 加 MutationCache 全局兜底；MetaPanel 删除确认改字段名身份消除下标前移误删；GlobalSearch 接 AbortSignal
- **a11y 批清偿**：三处 combobox 补 ARIA（AddReminderDialog/TemplateCombobox/PartyPicker 各按自身 DOM 结构接）；15 处纯图标按钮补 aria-label

#### 优化

- **useMediaQuery 上提 src/hooks/ 并收敛响应式**：HomePage isMobile() 读瞬间值改 hook（拖窗跨断点正确更新）；CalendarPanel resize+防抖改 matchMedia 双断点推导（断点内拖窗零重渲染）
- **品牌升级**：法穿AI Copilot → **法穿SI Copilot**（前端：登录品牌栏/移动端标识/导航栏/网页标题/落地页打字机动画；后端：admin 界面标题、OpenAPI title、MCP server、日历 ICS prodid、contract_review 报告页脚与 Word 修订人默认值、邮件发件人默认值及 DB 实值、django.po 重编译；根/前后端 README 与 Makefile 同步）
