# v27.20.13 — trafilatura 作正文抽取的**可选兜底**（并更正原证据）

> 承 `v27.20.12`。对应 `TECH-DEBT.md` ④。

## 先更正一条证据（重要）

`TECH-DEBT.md` 原写「政务页实测只抽到 830 字，页面实际更长」——**实测发现这是错的**：
拿 `rsj.sxjz.gov.cn` 那页同时跑选择器与 trafilatura，得到 **753 / 694 字**，
即那页正文本身就这么长（是个问答短页），不是我们漏抽。
所以 ④ 的性质从「抽取质量 bug」降级为「给老站/怪排版上保险」。

## 改动

- 新增 `uv add trafilatura`（2.3.1，连带 `courlan` / `htmldate` / `justext` 等纯 Python 包），
  `pyproject.toml` + `uv.lock` 同步。
- `fetch_url._extract_text_with_fallback`：**只在选择器抽到的正文 < 300 字时**才请
  trafilatura 二次抽取，且取更长的那份。300 与 trafilatura 自己的
  `MIN_EXTRACTED_SIZE=250`（级联降级闸门）同量级。
- **不做整条管线替换**：trafilatura 的输出形态（段落/表格）与现有「表格转 Markdown 行 +
  分块续读 + 注入包裹」基线不同，直接换会让下游全部漂移。先用它补「选择器几乎抽不到」的
  那一类页面，观察命中率与稳定性后再谈替换。
- 可选依赖纪律：`import trafilatura` 失败时返回空串，**静默退回**选择器结果 ——
  精简环境（比如只装了最小依赖的沙箱）不会因此抓不了网页。

## 测试

`test_fetch_url.py` 补 3 例：选择器抽不到时用兜底、选择器够好**不调用**兜底（省时间）、
trafilatura 未安装时返回空串并保留选择器结果。
