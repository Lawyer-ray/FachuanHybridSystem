# v27.20.1 · 域外法查明：把「11 国到底几国能核」测出来，并修掉测出来的 5 个缺陷

> 承接 `v27.20.0`。涉及 `backend/plugins`（子模块 `barlc_asean_law` 1.1.1 → 1.2.0）、
> `backend/mcp_server`、`backend/apps/legal_research`（**含 1 篇未应用迁移**）、`frontend`。
>
> **本篇的全部结论来自实测**：11 国逐国拉真 BARLC 正文（40 次请求），不是读代码推断。

## 一句话定位

| 问题 | 之前 | 现在 |
|:--|:--|:--|
| 国别清单 | 返回 22 条，其中 **10 条是语种码**（`LANGUAGEZW`…），模型会把它们当国别传 | 只回 11 国 + 东盟组织（12 条） |
| 国别码猜错（马来是 `LAWCOUNTRYMLXY`，不是 `MY`） | 空结果 → 报「不存在该引用」 | `reason="unknown_country"` + 合法清单 |
| 柬埔寨民法典（印度法系纯数字体例） | 切出 **37 条，全是误切**（正文交叉引用被当条款头） | **1305 条**，首条 `1. General principles of private law` |
| 泰国 CCC（448 页 PDF） | 页数上限 400，末条只到 1606 | 上限 1200，切出 **1613 条** |
| 马来/新/菲/文/缅（`HaveEnglishPdf=0`） | 取英文正文抛异常 → 整个核验失败 | 真回退本地语；取不到就报「无结论 + 需人工」 |
| 短法名 vs 长正式标题（`Civil Code` → `The Civil Code Of Cambodia`，字符比 0.42） | 判「不存在该引用」 | 词序连续包含 → 命中，但**不**会把 `Civil Code` 认成 `Code of Civil Procedure` |
| 生效版本 | 三个日期拿了从不使用 | `as_of_date` + `version_warnings`（生效日晚于时点 / 修订晚于时点） |
| 来源追溯 | `source_url` 恒空 | 回带 BARLC 详情页地址，前端「原站打开」 |
| 核验结果 | 完全不落库 | 新增 `ForeignLawVerification` 台账（**迁移 0016 未应用**） |

## 后端

#### 新功能

- **落库留痕**：新增 `apps/legal_research/models/foreign_law_verification.py` + `services/foreign_law_verification_service.py`，
  HTTP 入口写一行台账（请求侧 / 结论侧 / 溯源版本 / 合同归类 / 判定开关快照）。
  **只存条文 sha256 与长度，不存全文**；写入 fail-open（写失败不影响核验返回）。
  MCP 直连工具路径本期**不落库**（MCP 进程拿不到律师身份，会在 docstring 里写明，避免被当全量台账）。
- **生效版本校验**：`asean_law_verify` 新增 `as_of_date`（引用时点），命中 `effective_date`/`revise_date`
  比对结果写入 `version_warnings`。BARLC 没有「是否现行有效」字段，所以**只做日期比对、绝不宣称有效**。
- **解释上下文**：相邻条（前一条/后一条）作为 context 注入判定器，只用于理解术语与范围；
  `quote` 必须出自被引条本身（证据闸硬拦），避免「定义在别条」被判成「本条支持」。
- **合议全局并发闸门** `JUDGE_CONCURRENCY=9`（进程级），与合同评审侧 `Semaphore(8)` 同量级。
- 检索命中补 `revise_date` / `country_code` / `source_url`；`asean_law_read` 补 `revise_date`。

#### 修复

- **国别清单污染**：`GetDBCategory` 把语种节点混在国别里，按 `LAWCOUNTRY*` 前缀过滤。
- **国别码非法**：新增 `BarlcUnknownCountry`，主动校验并回带合法清单（不再静默空结果）。
- **纯数字体例**：新增兜底，且当 Section/Article 把多条粘成一条（中位段长 > 4000 字）时**改选**数字体例；
  启用前三道判据（条数 ≥3、编号大体递增、平均每条 ≥100 字），宁可判「切不出」也不切错。
- **取正文异常时回退本地语**：此前只在「切出 0 条」时回退，异常路径直接上抛，与 `read` 工具行为不一致。
- **页数上限 400 → 1200**：泰国 CCC 448 页被截断，高条号永远查不到。
- **短法名的假阴性**：新增「词序连续包含」匹配（`civil code` ⊂ `the civil code of cambodia`），
  同时**不会**把 `Civil Code` 认成 `Code of Civil Procedure`（顺序不同即拒）。
- **按款引用**：`第4条第2款` / `4(2)` 降级到条级核验，并在 `review_reasons` 里明说「只到条级」。
- **`jury_tokens` 重复计费**：新增 `cached` 字段，缓存命中时可过滤后再求和。
- 日志：条款切分的重复序号告警从 N 条合并为 1 条（越南民法典一部就触发 20+ 条，会洗掉真错误）。

#### 优化

- 详情/正文/国别列表三处 TTL 缓存；HTTP 客户端复用；账号进日志前遮蔽。

#### 数据库

- **新增迁移 `legal_research/0016_foreign_law_verification`，尚未应用**（按迁移纪律不擅自 `migrate`）。
  上线前需：`manage.py migrate legal_research`。
