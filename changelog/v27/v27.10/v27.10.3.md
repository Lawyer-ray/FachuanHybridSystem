# v27.10.3 — SI Copilot：`/` 命令菜单、技能按需加载、上下文水位与手动压缩

## 前端

#### 新功能

- **`/` 命令菜单**（`Composer` + 新组件 `SlashMenu` + 新 hook `use-slash-menu`）：输入 `/` 打开浮层，↑/↓ 导航、Enter/Tab 选中、Esc 关闭；技能项补全为 `/skill:名字 ` 前缀（后端 pi 在发给模型前展开全文），命令项（`/compact` 手动压缩）直接调端点生效；无会话时 compact 禁用并提示「先开始对话」。
- **上下文水位显示**：Composer 底栏显示「上下文 N%」（done 事件与 `/stats` 接口回填），≥80% 转警示色；水位未知时隐藏。
- **压缩可见性**：自动压缩进行中显示「正在压缩上下文…」，不再无声发生（此前律师只会看到 AI 突然「失忆」）。

#### 优化

- `types.ts` 的 SSE 事件类型改为 re-export 自动生成的 `sse-events.ts`（单一来源，禁止手抄漂移）。

#### 测试

- `Composer.dom.test.tsx` 补菜单（打开/过滤/键盘/Esc/禁用项）、水位、压缩中状态用例；`domain.test.ts` 补菜单纯函数用例；`api.test.ts` 补四个新接口契约；`store.streaming-events.test.ts` 补 done 带水位与 compaction 事件用例。

## 后端

#### 新功能

- **技能注入面**：`rpc_client` 启动参数恒定 `--no-skills` + 按用户启用清单逐个 `--skill <目录>`；`AgentSkillPreference` 模型（用户 × 技能，偏好只记差异、缺省全启用）+ 迁移 `0014`；`skill_service` 扫描 `pi/skills/` 的 SKILL.md frontmatter 并合并偏好。
- **技能端点**：`GET /agent/skills`（清单 + 启用态）、`PATCH /agent/skills/{name}`（启停，非法名/未知名 404）。
- **会话统计端点**：`GET /agent/sessions/{id}/stats`——从最新 `AgentRun` 读 token 用量与上下文水位（读库即可，不起 pi 进程）。
- **手动压缩端点**：`POST /agent/sessions/{id}/compact`——起 pi 续写 session 文件执行同步压缩（走 `compaction-takeover` 确定性编译，与自动压缩同源），写审计消息并返回新水位；池忙 429、无历史幂等返回 `compacted=false`。
- **SSE 契约**：新增 `compaction` 事件（start/end）；`done` 事件可选携带 `context_used_tokens` / `context_total_tokens`。
- **水位落库**：`AgentRun` 新增 `context_used_tokens` / `context_total_tokens`（nullable：拿不到不编造 0）；每轮结束、pi 关闭前取一次 `get_session_stats`。
- **压缩留痕**：自动压缩完成时写一条 `context_compaction` 工具消息（Django 消息表是回放权威）。

#### 修复

- **技能面污染修复**：启动参数显式 `--no-skills`——此前 pi 会无条件自动发现宿主机 `~/.agents/skills`（本机 203 个安全渗透技能）并注入系统提示词，烧 token 且内容不受仓库管控。

#### 测试

- 后端新增 33 个测试：`skill_service`（扫描/偏好/非法名）、rpc_client（`--no-skills`/`--skill` 拼装、水位解析容错）、bridge（compaction 翻译）、API 集成（技能/统计/压缩的契约形状、鉴权、归属、错误映射）。

#### 说明

- `GET /skills` 与 `PATCH /skills/{name}` 的技能库随代码发布（`apps/agent/pi/skills/`，与既有 `get_agent_skill` MCP 工具共用同一份库）；模型自主查阅（MCP 工具）与律师显式点名（`/skill:`）双通道并存。
- `apps/agent/README.md` 新增「5.2 技能（skills）：安装与使用」：双通道分工、SKILL.md 安装五步（命名约束/`disable-model-invocation`/路由表/部署无重启）、律师使用方式、内部机制与安全红线（技能库写权限仅部署管道）；端点表补齐本轮 4 个新端点。
- 迁移 `0014` 刻意剔除了 makemigrations 自动带出的 `agentattachment.ref_contract_id` AlterField（既有模型/库漂移，沿 0010/0011 先例不混入特性迁移）。
