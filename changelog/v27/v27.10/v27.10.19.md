# v27.10.19 — 修「保存过的宽度跨窗口失效」导致左栏整栏消失

## 前端

#### 修复

- **换到更窄窗口后左栏被压到 0**：`localStorage` 里记的是「当时那个窗口」拖出来的宽度，换了窗口后照用会把容器撑爆。实测存 `1140` 换到 1400px 屏：左栏只剩 **174px**、表格 **268px**（正好只剩日期/类型/状态三个定宽列，事项与交付物两列归零，中文逐字竖排），与你截图的现象完全一致。
- 修法：**用户拖过的宽度也必须夹在当前容器允许的范围内**，两个上限取小——
  - `hardMax` = 容器 × `maxRatio`（默认 68%）
  - `keepLeftMin` = 容器 − 左栏下限 560（保证事项表放得下）
- `autoWidth` 与用户宽度共用同一套上下限，避免两处逻辑漂移。

#### 测试

- Playwright 实测（1400px 视口，预置不同 localStorage 值）：
  - 存 900 → 左栏 534 / 右栏 780 / 表格 532
  - 存 1140 → **左栏 534 / 右栏 780 / 表格 532**（修前 174 / 1140 / 268）
  - 存 1200 → 左栏 534 / 右栏 780 / 表格 532
- 五档视口（1200–1600）左栏表格稳定 532px；800px 窄屏右栏钳到 360。
- 单测补「容器宽度未知时不钳制上限（首帧不误伤）」。

#### 说明

- `LEFT_MIN = 560` 是算出来的：日期 116 + 类型 68 + 状态 84 = 268 三个定宽列，再加事项与交付物各需 130 才容得下中文标题。
