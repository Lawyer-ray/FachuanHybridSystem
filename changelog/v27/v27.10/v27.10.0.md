# v27.10.0

详情页 AI 工作区整体升级：双归属文件夹引用（案件+合同）、工作区左置与聚焦模式、超级助理业务归属感知、会话列表分组。含数据库迁移 `agent.0009_add_ref_owner_kind`（已应用工作库）。

---

## 前端

#### 新功能 · 引用泛化到案件绑定文件夹 + 目录引用

- **案件文件/文件夹可直接拖入对话**：此前只有合同目录树的文件能拖；现案件卡片文件夹视图、合同目录树的文件**与文件夹**（`isFolder`）均可拖入法穿SI超级助理，双通道投放（自定义 MIME + 系统 Files）。
- **目录引用**：拖入文件夹后消息生成 `[已引用目录：…]` 块（不入附件表），AI 用新工具 `list_folder_files` 先列目录再按需读取；chips 用实心 Folder 图标 + 尾部 `/` 区分。
- **页面感知**：全局助手（⌘J）消息注入 `[当前页面：…]` 锚点（路由变化后首条），AI 可拿实体 id 主动了解页面内容。

#### 新功能 · 详情页 AI 工作区（法穿SI超级助理）

- **专属区域取代侧边栏弹窗**：宽屏（≥1280）详情页第三列改为内嵌工作区；窄屏回落全局浮层。名称「法穿SI超级助理」，带「本案/本委托独家」徽标。
- **工作区移到最左列**：拖宽把手在右缘，向右拖变宽。
- **聚焦模式**：拖动越过共存阈值（容器-756px）即隐藏案件卡与档案栏、工作区独占整行；拖回恢复三列；聚焦态由拖动触发并持久化（记忆宽度在窄容器只钳制显示，不误入聚焦）。
- **窄屏钳制**：ResizeObserver 实测容器宽，工作区列宽按容器收窄，任何屏不溢出。
- **对话内容限宽居中**：消息栏与输入区 `max-w-3xl(768px) mx-auto`（面板拉宽/满屏时阅读行宽舒适、留白对称；窄面板不受影响）。

#### 新功能 · 超级助理业务归属感知

- 业务范围内**每轮消息注入** `[当前业务：本委托「xx」 contract_id=N]` 锚点（pi compaction 可能压掉首轮上下文，不重复注入模型会「失忆」反问「哪个案件」）；本地气泡折叠为公文包 chip。E2E 验证模型开口即自报归属。

#### 新功能 · 会话列表按业务范围分组

- 侧栏「项目分组」形态：委托/案件各成组（组名 = 委托人客户名 / 案件名），后台任务与通用对话兜底组；组头可折叠、组内超 5 条收进「显示更多」；业务范围模式（context）保持平铺。

#### 新功能 · 空态欢迎页与视觉升级

- 空态从占位文案改为引导式欢迎页：单色 orb + 问候语 + **可点快捷任务卡**（案件/委托域：梳理材料/进展与下一步/对方风险检索/文书起草思路；全局：我的案件/到期期限/未收款汇总/今日待跟进），点击即发送。
- AI 身份单色视觉：orb（暗色自动明暗反转）、发送钮微交互、「深度思考中」灰阶流光、输入区聚焦光环、拖文件进面板整圈高亮；`prefers-reduced-motion` 下动效全关。

#### 新功能 · 提问人头像

- user 气泡右侧显示律师头像（`avatar_url`），未设置回退真名首字圆形字标；auth `User` 类型补 `avatar_url`/`real_name`，navbar 回填透传。

#### 修复

- **超级助理高度（越拉越高看不到输入框）**：sticky 初始位置仍在文档流，按满视口高的固定值假设错误——改为 JS 实测 `innerHeight − max(top, navbar+14) − 14` + scroll/resize 跟随；记忆直开（loading 早退）时 effect 依赖补 `deal` 数据到达后重跑。
- **案件页附件溢出卡片**：chip `max-w-full min-w-0` + 内层 truncate。
- **附件名去后缀**：`shortDocName` 剥扩展名与 `_` 后缀。
- **短信链接超链接化**：`splitLinkText` 识别 URL（保留 query 串、不吞中文），渲染为「查看链接 ↗」。

## 后端

#### 新功能 · 双归属文件夹引用（案件 + 合同）

- **`AgentAttachment.ref_owner_kind`**（`contract`/`case`，迁移 `0009_add_ref_owner_kind`，存量行按 contract）：`ref_contract_id` 语义泛化为「引用归属 id」。
- **`folder_refs` 服务双归属**：`BoundFolderBrowseService` 基类按 kind 分发到合同/案件浏览服务（同一套行级 ACL + 路径逃逸校验）；案件引用标识 `folder:case:{id}/{subpath}`。
- **API**：`POST /agent/folder-refs` 入参 `{kind, owner_id, subpath}`；content/pages 端点同步双归属；未知 kind 拒绝（400）。

#### 新功能 · MCP 工具 `list_folder_files`（工具面 400 个）

- 列出合同/案件绑定文件夹某目录的直接子项（子目录 + 文件含大小），目录引用的浏览入口；与 `read_folder_file`（contract_id/case_id 二选一）配套。

#### 新功能 · 会话列表 `scope_name` 注水

- `GET /agent/sessions` 批量注水业务范围名：案件取 `Case.name`；合同取**委托人（PRINCIPAL）客户名**（无委托人回退合同名，实体已删回退「案件/合同 #id」）；`pk__in` 批量无 N+1，跨域模型 `apps.get_model` 延迟解析保持 agent 单向依赖。

#### 修复

- **自动标题剥锚点**：首条消息带 `[当前业务：…]`/`[当前页面：…]`/`[已引用…]` 前缀时先剥锚点行再截 30 字（此前列表出现「[当前业务：本委托] xx公司…」标题污染）。
