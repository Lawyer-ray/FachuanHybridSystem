# v27.10.7 — 常法页版式照 53 号原型：服务期带 + 服务事项流

## 前端

#### 新功能

- **服务期带**（`TermBar` + `term-timeline.ts`）：页面顶部一条进度条，已流逝比例、最后 20% 预警斜纹、今天红色竖线，右侧显示「还剩 N 天 / 今天到期 / 已超期 N 天」。纯日期文字「2025-10-22 → 2026-10-21」要读两遍才反应过来，一条进度条一眼就知道。
- **服务事项联动刻度**：事项按日落在同一条轴上（`ticks`），刻度越密说明那个阶段越忙、空档说明服务空转——律师自己也能看出要不要催客户。同一天多个事项聚成一根并记密度（`count`），轴外事项丢弃、非法日期忽略、未开始/超期把进度钳到 0 与 1（不出负宽度或溢出）。
- **服务事项流**（`ServiceItemStream`）：左栏主角从「合同文件夹」换成「本年度服务事项」表格——日期 / 类型 / 事项（含对象）/ 交付物 / 状态。文件夹只回答「文件在哪」，而常法顾问真正要回答的是「这一年为他做了什么、哪些还没交付」；文件从「目录树里的一个名字」变成「某项服务的产出」。用表格而非卡片流：30+ 事项时卡片会变成一堵墙。

#### 优化

- **版式改为左宽右窄**（照 53 号原型）：左栏服务事项流、右栏合同要素 + 合同文件夹 + 页内预览。此前是非诉页左栏独占文件夹，右栏被压到 400px。
- **文件夹并入右栏合同要素区**：`DetailRail` 新增 `folderOwnerId` / `folderSelectedSubpath`，让树能绑定到指定委托并高亮当前预览那一行；树高 320 → 420px。

#### 测试

- `term-timeline.test.ts`（13 例）：进度与剩余天数、起止非法返回 null、未开始/超期钳位、刻度位置、轴外丢弃、同日聚合密度、排序、今天标记、非法日期容错、预警区起点、文案与色调分档。

#### 说明

- **服务事项数据暂由两处合成**：期限（已有真实数据）与合同文件夹里的文件（交付物的直观来源）。后端「服务事项」表尚未建，等它到位后只需替换 `serviceItems` 的取数，渲染与时间轴联动不用改。
- **`today` 由页面传入**（不在此处取 `Date.now()`）：便于测试固定日期，也便于跨天刷新时只改一处。
