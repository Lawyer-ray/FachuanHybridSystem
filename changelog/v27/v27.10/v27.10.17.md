# v27.10.17 — 修窄屏下预览栏撑爆容器、左栏被挤没

## 前端

#### 修复

- **窄屏下列表中文逐字换行、左栏几乎消失**：`localStorage` 里记的是宽屏下拖出来的 `900px`，窗口缩到 800px 后右栏仍按 900 渲染 → 撑爆 740px 的容器，左栏被压到几乎为零。改为用 `ResizeObserver` 实测容器宽度，容器比记住的宽度还窄时**不再套用固定宽度**（`stacked` 态）。
- **竖排时容器量不到**：`containerRef` 挂在只在「有预览」时才存在的容器上，而测量 effect 依赖空数组只跑一次——首次渲染没有该节点，`containerWidth` 恒为 `null`，`stacked` 永远不成立。改为依赖 `layoutKey`（`picked ? 'split' : 'stacked'`），布局切换时重新测量。
- **竖排下分隔条仍占 10px 且无法拖动**：上下堆叠时没有左右分栏可分，加 `hidden` 在 `max-[1100px]` 下隐藏（用 CSS 而非不渲染，保持 DOM 稳定、避免拖拽中的布局跳变）。

#### 测试

- Playwright 实测（600 / 800 / 1600 三档视口）：
  - 800px：容器 740、右栏 900 → **601**（受 maxRatio 钳制），左栏 740 完整显示
  - 600px：右栏收缩到 576 与左栏同宽（上下堆叠）
  - 1600px：拖拽仍正常（720 → 911）

#### 说明

- 这类「localStorage 跨视口失效」的问题单测测不出来：jsdom 没有真实布局，`ResizeObserver` 与 `getBoundingClientRect` 都不返回有意义的值。只能靠真实浏览器按视口验收。
