## 一、未绑定合同文件夹：先查绑定，再决定要不要拉目录（并可手工绑）

| 之前 | 现在 |
|:--|:--|
| 合同没绑文件夹时，右栏照样去打 `GET /contracts/{id}/folder-entries` → 一条 404，界面只有一句兜底错误，律师分不清「没绑」还是「目录坏了」 | 先查 `folder-binding`（未绑定返回 `null`）：未绑定就一句话 + 「＋ 绑定文件夹」；已绑定才渲染树。实测 `/projects/442` 只发 `folder-binding` 一条请求，**没有 404** |
| 老项目 / 从材料包建出来的项目没有绑定记录，只能去 admin 里找 | 弹窗填**服务器上的绝对路径**即可绑定（`POST /contracts/{id}/folder-binding`），成功后立刻出树；已绑定的可「改绑定」 |

## 二、案件卡只加一个「办理」，四件事在里面

四件事各摆一个按钮会把案件卡变成工具栏。现在：**一个「办理」→ 右侧抽屉四行**，
每行「一句就绪状态 + 一个主按钮」，没有二级菜单、没有历史列表——less is more。

| 行 | 就绪状态（真实读取） | 主按钮 |
|:--|:--|:--|
| 一张网立案 | 法院账号已配 / 缺账号 · 法院名 · 插件可用 / 仅浏览器自动化（`GET /court-filing/case-info/{id}`） | 开始立案 → `execute` → 轮询 `session` |
| 申请担保 | 诉前保全 / 已有案号 · 保险公司（`GET /court-guarantee/case-info/{id}`） | 申请担保 → 同上 |
| OA 立案 | OA 系统名 · 凭证已配 / 缺凭证（`GET /oa-filing/configs`） | 提交 OA（**合同级**，OA 按委托立不按审级） |
| 项目归档 | 案卷清单 X/Y 齐备（缺哪几项直接列出来，`GET /contracts/{id}/archive/checklist`） | 归档项目（二次确认：会把在办案件一并结案，不可逆） |

三条诚实原则写在组件头注释里：**点下去是真提交**（缺凭证直接禁用，不让人点了才失败）；
**异步会话原话展示**（轮询 `status` / `message` / `error_message`，不假装秒完成）；
**归档单独确认**（连带结案且不可回退）。

## 走查中抓到的一个真 bug

`getArchiveChecklist` 一开始用了 CRUD 客户端，拼出 `/contracts/contracts/448/archive/checklist` → **404**。
归档端点和文件夹同前缀（`/contracts/{id}/archive/...`），必须用 `contractFolderApi`。
单测 mock 了 API 抓不到这种错——是真浏览器里看到「归档清单读取失败」才暴露的。

## 已知取舍

- 立案 / 担保的**类型与引擎**用后端建议值，抽屉里不给改（改要三个控件，一次性低频动作不值）；
  真要换类型，走银行批量诉讼页那套完整面板。
- 归档**只认「必填项齐备」**才让点。清单判定沿用后端 `required`，前端不另立标准。
- 立案/担保的会话轮询上限 3 分钟；超时就把最后一次 status 留在行里，不无限转圈。
