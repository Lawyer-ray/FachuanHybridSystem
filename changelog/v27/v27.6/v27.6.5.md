# v27.6.5

首页快速记一笔：支持直接 ⌘V 粘贴截图进输入行——截图走既有文书识别链路（上传 → 识别 → 人工确认日期），和点 📎 / 拖拽同一条路。

## 前端

#### 新功能：快速记一笔支持粘贴图片

- `QuickAdd` 容器加 `onPaste`：剪贴板里有文件时 `preventDefault` 并接住，走与 📎 / 拖拽相同的 `pickFile` 校验链路；纯文字粘贴不拦截、保持输入框默认行为
- 新增纯函数模块 `clipboard-file.ts`：剪贴板截图是浏览器给的泛名（`image.png` / `blob`），而 recognize 端点按**文件名后缀**校验（`.pdf/.jpg/.jpeg/.png`），不改名会被整单拒收——按 MIME 补全扩展名，并换成「粘贴图片-YYYYMMDD-HHMMSS.ext」带时间戳的名字（后端记录里一堆 image.png 分不清是哪次）；名字本身有信息量的（如 Finder 复制的「传票.pdf」）原样保留
- 文案：placeholder 与空输入提示补「可粘贴截图」；`image/jpeg` 统一落 `.jpg`，白名单外的 MIME（如 webp）照实落扩展名，让校验报出具体格式
- 测试：`clipboard-file.test`（node）9 例覆盖泛名改名 / 真名保留 / files→items 兜底 / 纯文字放行；`quick-add-paste.dom.test`（jsdom）4 例接线验证（粘贴出胶囊 + 弹窗打开 / 拒绝不进文件态 / 纯文字不拦截）；vitest 637 / tsc -b / ESLint / build 全绿
- 真机探针（IAB Chromium，测完清数据）：合成 PNG 以真实 `ClipboardEvent` 派发到输入框 → 胶囊显示「粘贴图片-20261018-150254.png」→ 识别弹窗自动打开并进入上传；探针产生的识别任务与物理文件已按 id 精确清理
