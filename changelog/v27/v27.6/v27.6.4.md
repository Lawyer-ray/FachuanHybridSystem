#### 修复：切分 / 合并后的材料同名难分、合并的一份跳到末尾

- 现象（用户在 384 上实测）：切三刀后左栏出现三份名字完全相同的材料（都叫源文件名）；选页「合并为一份」后，并出来的那份被追加到整个文档最末尾、固定叫「合并材料.pdf」——页序被打乱，看起来像凭空多了一个文件
- 根因：「在此切开」留下的尾段、「切出」留下的头 / 尾段、合并留下的余段都直接沿用源文件名，只有被切出的那份带 `-P起始页`；`mergePagesIntoNew` 固定 `segs.push`
- **默认名统一规则**（`labels.ts` 新增 `defaultSegName` / `isAutoSegName` / `withDefaultNames`）：整份 = 源文件名；非整份 = 「源名-P起始页.ext」，跨源取首页所在的源。切开 / 并入上一份 / 切出 / 合并 / 删页五条路径末尾统一经 `withDefaultNames` 刷新——页区间变了名字跟着变、并回整份就变回源名；**用户改过的名原样保留**（判定：名字不是任一源文件名、也不匹配「源名-P数字.ext」）
- **合并的一份放回原位**：插在首选页原来所在段的位置（该段剩下的前半留在前面，合并段紧随其后），不再追加到末尾；命名走统一规则，不再叫「合并材料.pdf」
- **打开老草稿时刷新一次默认名**（`store.open` 对已存草稿 `withDefaultNames(ensureSegIds(ds))`）：384 里那三份同名的会在下次打开时自动变成各带起始页，不用手动改
- **页区间可见**（`segRangeText`：连续「P5–19」、断续「P3, P7–9」、跨源「跨源」）：左栏每行名字后标区间（整份仍只显示「整份」），段头改为「P5–19 · 15 页」
- 文案：选页浮条「将独立成一页新材料」→「将独立成一份新材料」；处理后 toast「新的一份已就位，记得选类型」
- 测试：`labels.test` +4 组（默认名规则 / 默认名判定 / 刷新含用户改名保留与整份回退 / 页区间文案）；`selection.test` 与 `segments.test` 按新契约更新（残段带起始页、合并段位置与命名、并回整份变回源名）；`ReaderBars.dom.test` 段头区间文案；vitest 611 / tsc -b / ESLint / build 全绿
- 真实 Chromium 端到端（临时管理员上传 5 页临时包，测完连包带附件删除）：P2 后切开 → 左栏 `探针-P1.pdf P1–2` / `探针-P3.pdf P3–5`；选 P2+P3 跨段合并 → 顺序 `P1 → P2–3 → P4–5`，并出的一份留在原位，三份分别叫 -P1 / -P2 / -P4

#### 新功能：⌘/Ctrl + 滚轮缩放画布、左栏右键菜单与行内改名、选类型自动命名

- **⌘/Ctrl + 滚轮缩放**（触控板双指捏合同样生效——浏览器把捏合派成带 ctrlKey 的 wheel）：必须用原生 `passive: false` 监听（React 17+ 的 onWheel 是 passive，preventDefault 拦不住浏览器整页缩放，实测 `clientWidth` 不变）；缩放前记下指针在内容里的相对位置，布局更新后把滚动条拨回去，指针下的页面不跑。指数步进，鼠标一格 ≈ ±25%，捏合连续平滑
- **选类型自动命名**：给段选了类型，仍用默认名的段名字跟着变成「类型.pdf」（同类型已有一份 → 「类型-P起始页.pdf」）——拆完选个类型名字就有了，不用再手改；改名后再换类型不跟随（`Segment` 新增 `fnAuto` 记录系统最近一次分配的默认名，fn 与之相等才算默认名；老草稿按名字模式回退判定，且类型名只认该段自己的类型）
- **左栏右键菜单**：段行右键 → 重命名 / 选类型（23 类子菜单，含清除）/ 并入上一份；源文件行右键 → 重命名源文件。改名是**行内输入框**（双击行或 F2 同样进入，Enter 提交、Esc 取消）；改过名的整份段显示名字而不是「整份」；名字超长走**中部省略**，让尾部的 `-P20.pdf` 露出来
- 键位说明（⋯ 菜单）补「⌘/Ctrl + 滚轮 = 缩放」「左栏：双击改名 · 右键选类型 / 并入」
- 测试：labels 默认名规则 / 类型跟随 / fnAuto 判定 +4 组，segments 换类型跟随与改名保留 +1，Rail 双击改名 / 点行跳转 / Esc 取消 +3；vitest 618 / tsc -b / ESLint / build 全绿
- 真实 Chromium 端到端（临时 3 页包，测完删）：ctrl+滚轮 100%→220%（页面 `clientWidth` 不变证明没触发浏览器缩放）→ 回 63% 被下限钳住；右键选「借条」→ 行变 `整份 | 借条`；右键重命名 → 行变 `身份证.pdf | 借条`
