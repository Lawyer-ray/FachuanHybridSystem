## 前端

#### 优化：当事人 / 收款 / 补充协议 / 合同要素全部迁入右栏卡

- 右栏卡节序：期限 → 当事人 → 法院联系人 → 律师 → 涉案与收费 → 收款 → 补充协议 → 合同要素；左列删掉整块档案沉底（`DetailArchive` 组件移除，节由新 `RailArchive.tsx` 承载）
- 当事人改右栏紧凑行：姓名 + 角色小字 + 复制，法定代表人/电话/证件号/地址一行灰字；我方在前、首个对方上方留白断组（不加分组标签）
- 收款改两行小记录（金额加粗 + 日期右对齐，摘要灰字），空时文案「还没有收款记录」并保留「＋ 记收款」入口；补充协议为名称 + 日期 · N 方当事人
- 合同要素去掉同卡重复项：收费方式 / 风险比例已在「涉案与收费」、代理阶段就是 stepper——同一张卡里同一信息不说两遍（`railFacts` 过滤）
- **右栏不再 sticky**：合同卡常比视口高（322 为 914px），钉住就得卡内滚动，收款/合同要素会被裁在看不见的地方，第一眼像「合同要素没了」；随页面流动才能一眼看全。期限仍是卡内第一节
- 测试：detail-domain 加 `railFacts` 去重 / `railParties` 排序 2 例，DealDetailPage.dom 的档案断言改为「全部档案节与期限同在一张右栏卡、左列无档案卡、风险比例只出现一次」；全量 675 例绿
