# v27.7.13

## 前端

### 新功能

- 办案详情页文件夹视图改为**树形就地展开**（不再面包屑导航）：绑定根下的目录直接铺开、逐层点击展开、懒加载；绑定根目录名不再单独占一层。
- 文件夹树支持管理动作：行内新建子文件夹、行内重命名（Enter 确认 / Esc 取消）、文件拖拽到任意文件夹行即上传（拖到空白区上传到绑定根）；成功静默刷新，失败才弹窗。
- 右栏合同卡新增「合同文件夹」节：直接浏览 / 管理合同绑定的文件夹（树形、限高滚动），未绑定时明确提示。

### 修复

- 案件日志附件同名去重：重放日志里同名不同 id 的重复附件只展示一个。
- 附件文件名隐藏括号内的案件背景描述（悬停仍见原名），列表更清爽。

## 后端

### 新功能

- 绑定文件夹目录管理 API（案件级 + 合同级各一套）：新建文件夹、多文件上传（multipart、同名自动 `_1` 序号、单文件 200MB 上限、文件名清洗）、重命名文件/文件夹；写操作与浏览共用同一套子路径收敛与属主行级 ACL。
- 合同绑定文件夹浏览 API：`GET /contracts/{id}/folder-entries`、`/folder-file`（与案件级同形契约）。

### 优化

- 浏览/管理逻辑提取为共享基类 `BoundFolderBrowseService`（`apps/core/filesystem/bound_folder_browse.py`），案件与合同子类只实现 ACL 与绑定解析两个钩子，避免双份收敛逻辑漂移。

### 修复

- 未绑定 / 云存储绑定 / 目录不可达统一返回 404 + 可读 message（原为 200 + browsable:false 占位，前端提示口径统一）。
