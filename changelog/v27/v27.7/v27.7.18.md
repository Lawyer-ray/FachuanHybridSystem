# v27.7.18

## 前端

### 新功能

- 文件夹树支持右键菜单：**复制 / 粘贴到此文件夹 / 重命名 / 删除**（案件卡与右栏合同树通用）。
  - 复制支持文件与文件夹，粘贴到任意文件夹行（同名自动加序号，不覆盖既有文件）。
  - 删除 = 移入绑定根下 `_已删除/`（带时间戳，可随时在树里找回，不做物理删除）；点击删除后行内二次确认，不叠模态弹窗。
  - 悬停快速动作（新建子夹 / 重命名）保留，右键菜单为完整入口。

### 优化

- 右栏「合同文件夹」的「新建文件夹」按钮并入节标题行（原来按钮单独占一行，与标题分离）。

## 后端

### 新功能

- 绑定文件夹复制与删除 API（案件/合同各一套）：复制支持文件夹递归、防复制到自身内部、同名自动序号；删除统一移入 `_已删除/` 回收目录并拒绝操作绑定根与回收目录本身。

### 测试

- 新增复制/删除单测 5 例（递归复制、同名序号、自身内部拒绝、回收目录移动、根目录保护）。
