# v27.7.21

图片自动旋转工具（`/admin/image_rotation/imagerotationtool/`）点击缩略图打开的大图预览弹窗只有标题和旋转按钮、图片区域一片空白，所有图片都预览不了。

## 后端

#### 修复

- **预览弹窗不渲染图片**：`openPreview` 把 `renderModalPreview` 以裸引用传给 `$nextTick`（`this.$nextTick(this.renderModalPreview)`）。Alpine 调用回调时不绑定 `this`，方法内 `this.selectedImage` 读到的是 `window` 上的 `undefined`，在首行 guard 处静默返回，`<canvas>` 停留在浏览器默认的 300×150 空白——弹窗能开、标题能显示、图片永远不出来，控制台也无报错。改为闭包捕获组件实例后调用（`var self = this; this.$nextTick(function () { self.renderModalPreview(); })`），与同文件 `resetAllRotations` 的写法一致
  - 回归来源：2026-06-21 把 90KB 的 `image_rotation.html` 拆成 partials + JS 模块（`ee131af4f`）时，原箭头函数 `() => this.renderModalPreview()` 被改写成裸方法引用
  - 弹窗内「左转 / 右转 / 180° / 恢复原始」按钮本就经 `this.renderModalPreview()` 正常绑定调用，所以按一下旋转按钮图片会突然出现——这也是症状只出现在「打开」这一步的原因
  - 验证：Playwright 无头 Chromium 真机 A/B 对照——热补丁回旧写法 canvas 300×150 零像素；修复版 canvas 随图 640×400 全像素绘制；两组控制台均零报错。探针拦截 `detect-orientation` / `POST jobs` 接口，不落库不落盘，临时账号测完即删
