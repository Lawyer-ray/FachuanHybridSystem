# v27.7.11

首页日历右键快捷菜单：右键事件行在光标处弹出「标记完成 / 删除」，删除不再需要先开详情弹窗再确认两步，右键即删。

## 前端

#### 新功能

- **右键快捷菜单**：桌面端右键日历事件行（`DayCell` 事件行 `onContextMenu`，拦掉浏览器原生菜单），在光标处弹小菜单（新组件 `EventContextMenu`）：
  - 「标记完成 / 恢复为未完成」——按当前完成态切换文案，复用既有批量完成链路（合并事件全成员一起标记）；
  - 「删除」（红字）——按后端 `can_delete` 显隐（谁创建谁删），合并事件带「共 N 条」提示；**直接下发不二次确认**（要的就是右键即删），误删兜底 = 乐观更新失败回滚 + 后端权限闸。删除走与详情弹窗同一个 `useDeleteReminder`，格子即时少一条、统计后端重算。
- 菜单在视口边缘自动翻转（`useLayoutEffect` 取真实尺寸，避免先闪一帧错位）；点空白 / 右键别处 / ESC / 滚动 / 改窗口尺寸均收起；z 基线 z-[119]/z-[120]，夹在本页抽屉（z-61）与弹窗基线（z-[130]）之间。
- 手机端不生效也不需要：≤760px 事件行不渲染（点格子开当日抽屉），右键是纯桌面增强。
