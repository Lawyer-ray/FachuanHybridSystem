本分支三块主线：**① 通行密钥（Passkey/WebAuthn）登录**——Touch ID / Windows Hello 代替密码，私钥只留在设备安全芯片、零第三方依赖，本地部署的终极免密方案；**② 公网部署栈**——nginx + gunicorn 落地，app.xlaw.top 脱离开发态直出（v27.3.0 提出的双轨方案收官）；**③ 登录体验打磨**——开场动画本机记忆 + login.css 分层拆分。7 commits / 38 文件 / +3,560−904。

## 后端

#### 新功能：通行密钥登录（social_auth）

- **`PasskeyCredential` 模型**（0008 迁移已应用）：credential_id 全局唯一、公钥（COSE/base64url）、签名计数器、rp_id（记录注册域）、可同步标记、最近使用时间；只存公钥侧信息，拖库不可伪造凭据
- **注册/登录双 ceremony**（`services/passkey_service.py`）：挑战存 Django session（key `webauthn_register` / `webauthn_login`，与 OAuth `oauth` 单槽隔离），读即删 + 300s TTL；登录用可发现凭据（allowCredentials 空），无用户枚举面；sign_count 严格递增，回退判克隆即拒绝；token 铸造复用 `bind_password_claim`，改密后 refresh 失效，与社交登录同口径
- **Origin → rp_id 白名单**：页面 Origin 必须精确命中 CORS/CSRF/FRONTEND_BASE_URL 白名单（与 Django CSRF 信任面同口径），DEBUG 下回环地址任意端口直通（vite `strictPort: false` 端口漂移不误伤）；凭据按 rp_id 隔离，localhost 与 app.xlaw.top 各自注册一次
- **7 个 API 端点**（`/api/v1/social/passkey/*`）：login options/verify（免登录，AUTH 限流）、register options/verify（需登录，AUTH 限流）、credentials 列表/重命名/删除（属主隔离，防越权）
- **WebAuthn 依赖**：`webauthn==3.0.1`（Duo Labs py_webauthn 改名后的官方包；**PyPI 上的 `py_webauthn` 旧名现指向他人同名异包，勿按旧名安装**）
- **Admin**：`PasskeyCredentialAdmin` 只读列表 + 删除（= 吊销设备），禁止手工新增
- 实现注记：端点全走同步 Ninja op（线程池）——Django session 懒加载是同步 ORM，同步实现回避了 async 上下文碰 session 的整类坑

#### 新功能：公网部署栈（deploy/，nginx + gunicorn）

- **双栈架构落地**：cloudflared → nginx:5091（dist 副本 / SPA 兜底 / hash 资产缓存）→ gunicorn:8003（UvicornWorker×2，DEBUG=0）；qcluster 常驻承载公网异步任务。开发栈（vite:5090 + uvicorn:8002）零改动，两栈同库同 Redis
- **macOS TCC 适配**：仓库在 ~/Downloads 下，launchd 后台进程读 Downloads 一律 EPERM/静默挂起（实证三组探针）——launchd 读取的脚本/env/nginx 配置/dist 全部经 `deploy/install.sh` 落运行时目录 `~/Library/Application Support/FachuanHybridSystem`；nginx 对仓库零读取（媒体走 Django FileResponse 鉴权回发）；venv python 需一次性手工授予完全磁盘访问权限（README 有步骤）
- **SECRET_KEY 生产升级**：原 37 字符过不了生产 fail-fast 闸门（强 SECRET_KEY / 显式 CORS / 禁 LAN），旧值备份于仓库外 `~/.fachuan-backups/`；JWT/session 失效一次需重新登录
- **命令族**：`make publish`（前端构建 + dist 同步 + collectstatic，构建即生效）/ `make stop` / `make start`（公网栈三服务停启）/ `make prod-restart` / `make prod-logs`；`deploy/` 本机部署配置退出 git 追踪（.gitignore，不入公共仓库）

## 前端

#### 新功能：通行密钥登录

- **登录页「使用通行密钥登录」按钮**（密码表单与社交登录之间）：WebAuthn + 平台认证器（Touch ID 等）双条件可用才渲染；一键完成 挑战→验证→落 token→进首页，全程同页无需回调中转；NotAllowedError 给「去账号绑定添加」指引
