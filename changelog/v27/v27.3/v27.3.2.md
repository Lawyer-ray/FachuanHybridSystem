# v27.3.2

通行密钥（Passkey/WebAuthn）登录：用 Touch ID / Windows Hello 代替密码，私钥只留在设备安全芯片里，服务器只存公钥；零第三方依赖（无需注册任何开发者账号、无审核、无回调跳转），是本地部署场景的终极免密方案。凭据按域名隔离（localhost 与 app.xlaw.top 各自注册一次）。

## 后端

#### 新功能

- **`PasskeyCredential` 模型**（social_auth 0008 迁移）：credential_id 全局唯一、公钥（COSE/base64url）、签名计数器、rp_id（记录注册域）、可同步标记、最近使用时间；只存公钥侧信息，拖库不可伪造凭据
- **注册/登录双 ceremony**（`services/passkey_service.py`）：挑战存 Django session（key `webauthn_register` / `webauthn_login`，与 OAuth `oauth` 单槽隔离），读即删 + 300s TTL；登录用可发现凭据（allowCredentials 空），无用户枚举面；sign_count 严格递增，回退判克隆即拒绝；token 铸造复用 `bind_password_claim`，改密后 refresh 失效，与社交登录同口径
- **Origin → rp_id 白名单**：页面 Origin 必须精确命中 CORS/CSRF/FRONTEND_BASE_URL 白名单（与 Django CSRF 信任面同口径），DEBUG 下回环地址任意端口直通（vite `strictPort: false` 端口漂移不误伤）
- **7 个 API 端点**（`/api/v1/social/passkey/*`）：login options/verify（无需登录，AUTH 限流）、register options/verify（需登录，AUTH 限流）、credentials 列表/重命名/删除（需登录，属主隔离）
- **WebAuthn 依赖**：新增 `webauthn==3.0.1`（Duo Labs py_webauthn 改名后的官方包，py.typed 齐全）
- **Admin**：`PasskeyCredentialAdmin` 只读列表 + 删除（= 吊销设备），禁止手工新增

#### 新增测试（unit + integration 共 30 例）

- unit：Origin→rp_id 校验矩阵（回环任意端口/白名单归一化尾斜杠与默认端口/拒外域拒 http 非回环/拒非法 origin）、挑战单次使用与 TTL、注册成功/跨账号重放/环境变化/库异常/重复凭据、登录铸 token（pwd_ver 断言）/挑战重放/计数回退/免计数认证器/未激活/未知凭据
- integration：凭据管理鉴权与越权隔离、登录 ceremony 全流程（挑战→断言→JWT→一次性）、注册流程（excludeCredentials 收敛）、Origin 缺失
- 实现注记：端点全走同步 Ninja op（线程池）——session 懒加载是同步 ORM，同步实现回避了 async 上下文碰 session 的整类坑

## 前端

#### 新功能

- **登录页「使用通行密钥登录」按钮**（密码表单与社交登录之间）：WebAuthn + 平台认证器（Touch ID 等）双条件可用才渲染；一键完成 挑战→验证→落 token→进首页，全程同页无需回调中转；NotAllowedError 给「去账号绑定添加」指引
- **账号绑定页「通行密钥」区块**：凭据列表（注册时间/最近使用/注册域）+ 添加（浏览器注册流程）+ 行内重命名 + 删除确认弹窗；域名隔离提示文案
- `passkey-coding.ts`：base64url ↔ ArrayBuffer 唯一换算边界 + 前后端契约类型（不赌 DOM lib 版本，仅在 navigator.credentials 边界收窄）；`passkey-api.ts`：预登录复用 socialClient 同源 cookie 模式，管理端点走统一 JWT 客户端
