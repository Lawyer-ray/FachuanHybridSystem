## 后端

### 修复：文书模板 admin 保存必炸 sub_type NOT NULL 约束（补录 1dbd91ff4）

**症状**：`documents.0016`（双空态清理迁移）把 `contract_sub_type` / `case_sub_type` / `archive_sub_type` 三列改为 NOT NULL 后，Django admin 编辑任何文书模板保存即 `IntegrityError`。

**根因**：`DocumentTemplateAdminService.prepare_save_data` / `validate_template_type` 对「与 template_type 不匹配」的子类型写 Python `None`，表单 save() 无条件赋给 instance，UPDATE 落库即撞 NOT NULL 约束。

**修复**：非匹配子类型一律归一为空串 `""`（与模型 `default=""` 对齐）；API/Ninja 路径 `workflow.update_template` 的「None=未提供」语义不受影响。

**测试**：新增 `tests/ci/unit/documents/test_document_template_sub_type_save.py`（service 单测 + 表单级端到端，修复前真实复现该 IntegrityError）。
