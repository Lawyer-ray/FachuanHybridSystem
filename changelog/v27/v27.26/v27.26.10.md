# v27.26.10 · 打通「Qoder 用自己的模型」：一个官方没写的环境变量

> **版本判定**：§1.2 同一条线（`v27.26.x` qoder）→ 第三位 +1（原号 `v27.28.5`）。
> 补丁号到这里正好到十：**下一份新版本无论哪条线都是 `v27.27.0`**（§1.1-B）。

## 一句话

| 之前 | 现在 |
|:--|:--|
| SDK 通道选 BYOK 自定义模型必失败（`You do not have access to this model service` / `The request could not be completed`），CLI 直跑却正常 | 根因找到：SDK 起 CLI 时带 `QODER_AGENT_SDK_ENTRYPOINT=sdk-py`，**该模式下 CLI 不加载 `settings.json` 里的 `providers`**（BYOK 就存在那儿），除非 `QODER_SDK_CUSTOM_BASE_URL_BYOK=1`。加上之后**一行修好** |
| 只能选 Qoder 自己的 17 个模型 | 模型下拉底部多一行「＋ 接入我的模型（平台网关）」：一键把 `LLMProvider` 注册成 qoder 的 BYOK provider，清单里随即出现 `<provider>/<model>`（如 `fachuan-gw/kimi-2.6`） |
| — | 真机验证：选了它之后 `delta: 收到`，`result_for.model = kimi-2.6`（**我们的网关模型**），`credits = 0`（不走 Qoder 额度） |

## 出处（不是猜的）

| 结论 | 来源 |
|:--|:--|
| 接自定义模型必须走 BYOK 注册（CLI `/model → Custom`；SDK `Daemon.create_byok_config`），不能在 `resolve_model` 里塞 `{url, api_key}` | 官方 `docs.qoder.com/zh/cli/custom-models`（「在 `/model` 的 Custom 页签添加」）+ 本仓库实测（未注册时报 `BYOK is disabled by your enterprise admin`，注册后 CLI 立刻可跑） |
| 动态选模型回调只能返回**已有模型 id**；文档称回调失败**不会**自动 fallback | 官方 `docs.qoder.com/zh/cli/sdk/model-policy` |
| 但实现会**静默回退到 Auto 并计费**（`BYOK_EXECUTION_UNSUPPORTED` 被吞） | GitHub `QoderAI/changelog-CLI#5`（桌面端实证，含日志与反编译函数名） |
| **SDK 模式下 CLI 不加载 `providers`，除非 `QODER_SDK_CUSTOM_BASE_URL_BYOK=1`**；且 `set_model` 返回 ACCEPTED 与执行不一致 | GitHub `agentscope-ai/QwenPaw#8077`（第三方接入的实测结论）+ 修复 PR `#8099`（就是加这一行 env） |

本仓库复现/验证（2026-11-27，本机）：

```
A) 不带该 env  → errors: ['The request could not be completed. Please try again.']
B) 带该 env    → BLOCK: 收到 | model=kimi-2.6 | model_usage: ['fachuan-gw/kimi-2.6']
```

`B` 里**保留了** `setting_sources=[]`（不继承用户设置里的 `permissions.allow`）：BYOK provider 通过
`--settings '{"providers": {…}}'` 内联传入，安全边界不放宽。

## 改了哪些文件

- `backends/qoder_backend.py`：`build_env` 恒带 `QODER_SDK_CUSTOM_BASE_URL_BYOK=1`（注释写明出处与症状）
- `backends/qoder_models.py`：BYOK 模型重新进下拉（`FACHUAN_QODER_SHOW_BYOK=0` 可隐藏）
- `backends/qoder_byok.py`：`register_platform` / `unregister` / `settings_payload` / `is_byok_model`
- `api/qoder_auth_api.py` + `schemas/qoder_auth_schemas.py`：`GET/POST/DELETE /agent/qoder/byok[ /platform ]`
- 前端：`AgentModelPicker.tsx`（底部「＋ 接入我的模型」）、`AgentRow.tsx`/`AnswerAgentMenu.tsx` 透传、
  `api.ts` 三个函数、`backend-types.ts` 的 `QoderByokState`
- 产物：`openapi.json` / `api-schema.d.ts`（+2 条路径 + 1 schema）

## 风险与遗留

- **静默回退**（`QoderAI/changelog-CLI#5`）：官方实现可能在 policy 失败时悄悄用 Auto 计费。本仓库
  的防护是「以 `result_for.model` 为准」——它是 `ResultMessage.model_usage` 的键，真回退了就会记成
  `Auto`，会话的 `llm_model` 与成本行也会跟着变；界面上能看出模型不是选的那个。
- 注册会把**网关 Key 写进** `<agent home>/qoder/config/settings.json`（BYOK 本来就这么存）。这是
  BYOK 的固有代价，别把它当普通配置文件对待（目录 0700）。
