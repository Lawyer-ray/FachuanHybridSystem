# v27.11.5

## 前端

#### 修复

- **记收款弹窗「识别」后 UI 错乱、保存按钮够不着**（`PaymentDialog.tsx`）：`DialogContent` 是单列 auto grid，识别结果那行 `truncate`（nowrap）文本的 min-content 把 grid 列撑到 658px，超出弹窗盒（512px），整个弹窗横向溢出、底部「保存收款」按钮被顶出弹窗右边界，表现为点击「识别」后布局错乱、无法保存。给弹窗加 `grid-cols-[minmax(0,1fr)]` 钳住列宽，截断真正生效。
- **记收款弹窗宽度比设计窄 108px**：原 `max-w-[620px]` 不带断点前缀，被基类 `sm:max-w-lg`（512px）压制从未生效，改为 `sm:max-w-[620px]` 正确覆盖。

#### 说明

- 已用 Playwright 在 1600×1000 / 1366×850 / 1280×800 三档视口真机回归：识别后 `scrollWidth === clientWidth`（618px）无横向溢出；「识别 → 保存收款」全链路 200，toast「收款已记录」，弹窗切「完成」态、右栏收款节即时刷新（测试数据已清理）。
