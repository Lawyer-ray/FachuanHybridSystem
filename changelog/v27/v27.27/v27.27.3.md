# v27.27.3 · 旋转入口收敛成一个「旋转」按钮，去掉「转正」这个词

> 同一条主题线（人工旋转）的第四次迭代，只加第三位。

## 一句话

| 之前 | 现在 |
|:--|:-|
| 旋转散在四个地方：工具栏「转正 ⌄」、页卡悬停三个小按钮、右键菜单四档、选页浮条一排按钮（外加左下角「已转正 N 页」浮条） | **只有工具栏一个「旋转 ⌄」**：作用于「所选 N 页 / 当前段 N 页 / 全部 N 页」，菜单里顺时针 90°、逆时针 90°、180°、重置旋转 |
| 「转正」在中文里更像员工转正，放在页面上别扭 | 统一叫 **旋转**；页脚仍保留 `180°` 角度徽标（那是状态，不是按钮） |

## 前端

#### 移除：四份重复入口

- `PageCell` 悬停的三颗小按钮（`↺ ↻ 0°`）与配套的 `RotateButton`、`onRotate` 属性、根节点的 `group` 类
- `PageContextMenu` 的旋转四项与 `MenuItem` 辅助组件（菜单回到「删除此页/所选」一件事）
- `SelectionBar` 的批量旋转按钮组与 `rotatedCount` / `onRotate` 属性
- `ReaderOverlays` 左下角「已转正 N 页 · 全部重置」浮条
- 连带清掉只为它们存在的管线：`ReaderColumns` / `ReaderBody` 的 `onRotatePages`、`onResetAllRotation`、`rotatedTotal`；`store.resetAllRotation`、`draft/page-rotation.ts` 的 `rotatedRefsOf`（均无其它调用方）

#### 保留

- 工具栏 **旋转 ⌄**（唯一入口）：作用范围自动取 所选页 → 当前段 → 全部，并写在按钮 title 与菜单标题里（「作用于 当前段 37 页」）
- 页卡悬停不再出按钮；页脚 `90°/180°/270°` 徽标保留（长列表里能扫出哪几页转过）
- 键盘 `R` / `Shift+R`：作用于选中页（键盘不占视觉，保留）
- 单页微调 = 勾选那一页再点「旋转」

## 说明与遗留

- 作用范围仍不做「永远全部」：转错 37 页的代价是再转回去，所以默认落在「当前段」
- 服务端与草稿层没有任何改动：`pageRot`、`rotations` 编码、四处出口（归案切页 / 卷宗归档 / 单段下载 / 整包下载）都不受影响，本次只动 UI 与文案
