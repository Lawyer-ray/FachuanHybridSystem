# v27.8.1

律所ID「同步」利冲回填补全：OA 利冲表分组标题自带「类别」（委托方 / 委托方关联方 / 对方当事人），此前解析只取「法律地位」丢掉了「类别」，导致我方被告案里类别为「对方当事人」的**共同被告**被按"法律地位与代理何方相同"误判为不回填的同案当事人——回填结果只剩原告一条。<!-- privacy-allow -->

## 后端

#### 修复

- `OAConflictData` 新增 `category`（分组「类别」）与行级 `customer_type / id_number / phone`；`extract_conflicts_from_html` 分组标题按「类别：X　法律地位：Y」分别提取两个维度，列式数据行加抓「身份证号码 / 联系电话」列并把「客户类型」列映射为 natural / legal；旧键值对形态同步识别「类别」，Playwright 提取器补「类别」分支
- 利冲分组改按 **OA 类别定阵营**（法律地位只作兜底启发式）：
  - 法律地位或类别含「第三人 / 利害关系 / 第三方」→ 第三人（不回填）
  - 类别「对方当事人」→ 对方当事人（**回填**，含法律地位与代理何方相同的共同被告 / 共同原告）
  - 类别「委托方」（非关联方）→ 并入委托人名单（回填 PRINCIPAL）
  - 类别「委托方关联方」→ 同案其他当事人（不回填，非我方）
  - 类别缺失才退回「法律地位 == 代理何方 → 同案其他，否则对方」的旧启发式
- 行级证件号 / 电话 / 客户类型随四组名单透出，当事人自动建库时优先按证件号匹配、缺失建库带上这些字段，利冲行不再只能按名称猜
