## 后端

`apps/agent`

#### 安全

- **`models.json` 明文密钥的创建窗口期**（`pi/model_config.py`，CodeQL `py/clear-text-storage-sensitive-data`，high）：该文件含明文 API Key，原本用 `Path.write_text` 写入后再 `chmod(0o600)`——先按默认 umask（通常 0644）建文件、再收紧权限，中间存在其他本地用户可读的窗口；且 `chmod` 失败会被 `contextlib.suppress` 静默吞掉。改为 `os.open(O_WRONLY|O_CREAT|O_TRUNC, 0o600)` 原子创建，创建瞬间即私有；再用 `os.fchmod` 兜底处理「文件已存在且权限更宽」的情况。

#### 优化

- **消除空 `except` 分支**（`services/event_bus.py` ×2、`services/approval.py`，CodeQL `py/empty-except`）：积压丢弃时补 debug 日志；中继协程收尾改为区分 `CancelledError`（正常取消）与真实异常（记 debug）；清理审批决定键失败从 debug 提升为 warning——键会按 TTL 自然过期，但值得留痕。
- **显式丢弃协程聚合结果**（`pi/rpc_client.py`，CodeQL `py/ineffectual-statement`）：`await asyncio.gather(task, return_exceptions=True)` 的返回值改为赋给 `_`，并注明是有意丢弃，避免被误判为无效语句。
