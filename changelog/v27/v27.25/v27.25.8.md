## 内容（`a57cf164a`，18 文件 +1417/−70）

### P0 强制性规则免疫（修真实漏判）

`rule_class=mandatory` 现在免疫立场对齐与两道闸。否则「抵押未解除不得转让」这种会导致
合同**无效**的条目，会被降成中危再被 25 条上限截掉。

这是本次唯一一条**真实漏判路径**，其余两条是结构性缺失。

### P1 阶段三段

规则与结论都带 `stage`（转让前 / 中 / 后）。`run.summary.stages` 四个键永远都在——
零结论也是覆盖证明，不是空白。清单可按阶段分组。

### P2 风险四维 + 条款的出生证明

结论带 `risk_source` 与 `source_weight`。提示词要求模型标来源；一页纸按来源回显，
律师能判断这是「法条硬约束」还是「情景假设」。

### 规则四类

`RuleClass`（`contractual` / `mandatory` / …）落进 `PlaybookRule.rule_class`，与阶段、风险维度、
后果档位一起构成「规则四类 + 阶段三段 + 风险四维 + 后果档位」的分类骨架。
