# v27.5.2

文件夹模板侧接入槽位体系：结构编辑器节点可标记槽位、列表页可见各骨架提供的槽位、保存校验 kind 合法性；并修复编辑器二次保存抹掉全部 kind 的缺陷。无迁移。

## 后端

#### 新功能：结构编辑器节点槽位下拉

- `folder_editor.js` 每个节点行新增「槽位」下拉（词表经 `json_script` 注入 change 页，按分类枚举序排列），新建/编辑骨架时可直接为节点标记落位槽位
- **修复 `extractStructure` 序列化丢 kind**：此前只序列化 id/name/children，任何人在编辑器里保存文件夹模板都会抹掉回填的 102 个 kind、槽位落位静默退化回旧绑定；现在选中才写 kind、未选清残留键

#### 新功能：列表页「提供槽位」列

- 文件夹模板列表新增列：N 类 + 分类聚合计数（如「20 类　通用×3　立案材料×7　庭审准备×6 …」），`title` 悬停显示全量槽位清单

#### 优化：解析预览与校验

- 结构预览树节点名后渲染 ⌘ 槽位徽标（`render_structure_tree` 接受 `slot_labels`）
- 保存时校验 kind 必须在词表内，错误信息指出「节点名 → 错误键」（防手写 JSON 打错字静默失效）；校验逻辑下沉 `FolderTemplateAdminService.validate_slot_kinds`

- `test_folder_template_admin_round2.TestRenderStructurePreview` 补 `django_db` 标记（预览现查词表）
