# v27.5.9

前端导航体验修复：切换 Navbar 标签不再闪烁（导航栏跨路由常驻 + 页面 chunk 预取 + 点击即高亮），材料预处理页去掉键盘快捷键提示文案。

## 前端

#### 修复：切换 Navbar 标签整页闪烁（无缓存首次切换尤甚）

- 根因（Playwright 探针实测坐实）：每个页面各自渲染一份 `AppNavbar`，且路由级 `Suspense` 的 fallback 是全屏 spinner——点击未缓存的标签后 54ms 内整页（含导航栏）被「正在加载…」替换，chunk 到了再整页重挂；限速下材料预处理域（含 pdfjs）要 4s+ 才回来，肉眼就是「导航栏消失→转圈→重现」
- 推手：10-03 审计批给 `PageErrorBoundary` 加的 `key={pathname}` 让错误边界连同里面的 `Suspense` 在每次 pathname 变化时都成为新实例。React 的 transition 只保护「已显示」的 Suspense 边界不退回 fallback，新挂载的边界会立即显示 fallback——react-router v8 `BrowserRouter` 默认的 `startTransition` 包裹因此失效。副作用：`/material-prep ↔ /material-prep/:id` 也整页重挂（页签、选中项等本地状态丢失，入场动画重播并与阅读器淡入叠加），10-02 写的 `PageFade` 同页判定逻辑实际已失效
- 壳层路由：`App.tsx` 新增 `AppShell` 布局路由（`RequireAuth` + 常驻 `AppNavbar` + `PageErrorBoundary` + 持久 `Suspense` + `<Outlet />`），四个页面（首页 / 材料预处理 / 办案 / 账号绑定）不再各自渲染导航栏与根容器。修复后探针：四次切换 `<header>` 全程同一 DOM 节点、零路由级 fallback，chunk 未到时旧页面保持到新页可渲染
- `ErrorBoundary` 新增 `resetKey` prop（`getDerivedStateFromProps` 比对，有错才清），`PageErrorBoundary` 改用 `resetKey={pathname}` 替代 `key`：崩溃后切路由仍复位，健康时子树实例与本地状态跨 pathname 保留
- 导航标签「点击即高亮」：`AppNavbar` 用 React 19 `useOptimistic(pathname)`，点击后在同一 transition 里先行把目标标签设为 `aria-current="page"`，chunk 下载期间立即有反馈（探针 17–87ms 生效），transition 提交后自动回落到真实 pathname；带修饰键 / 非左键点击不接管（交给浏览器开新标签），重复点当前页用 `replace` 不堆历史
- 页面 chunk 预取：`features/home`、`features/workbench` 出口导出 `preloadHomePage` / `preloadWorkbenchPage`（与 `lazy` 共用同一个 `import()`，浏览器模块缓存保证只下载一次）；`AppShell` 登录后 `requestIdleCallback`（Safari 退化 `setTimeout`）空闲预载三个主入口，`AppNavbar` 导航入口悬停 / 聚焦 / 触屏按下再预取一次兜底。实测空闲预载后「无缓存」首次进材料预处理 153ms 完成
- 导航栏高度收敛为 `:root { --app-navbar-h: 54px }`：`AppNavbar` 自身高度、移动端菜单下拉位置、`DeskPage` 拖放根容器「撑满导航栏以下视口」的最小高度（`min-h-[calc(100dvh-var(--app-navbar-h))]`）同源。壳层刻意保持块级布局——改为 flex 列时 `main` 上的 `mx-auto` 会吸收剩余空间让 `max-w` 失效（办案页 main 实测缩到 605px），已回退

#### 移除：`PageFade` 组件与材料预处理页键盘快捷键提示

- 删除 `components/shared/PageFade.tsx`：错误边界不再按 pathname 重挂后，页面组件实例在同页子路由间天然持久，入场动画直接挂到各页面 `<main className="app-page-enter">`——换页=组件换类型=main 重挂=播一次，同页子路由=实例不变=不重播。顺带消除 PageFade 原 effect 内改 state 再重挂的路径（持久化后会先提交一帧满不透明的新内容再拉回透明度 0 重播，本身就是一次闪）；也避免 `app-page-enter` 的 `transform`（`fill-mode: both` 动画结束后永久保留）成为整个 `<Outlet>` 子树里 `position: fixed` 阅读器 / 拖放层的包含块
- `DeskTabs` 删除「↑↓←→ 选择 / 空格 打开 / X 不接」三组 `<kbd>` 提示与分隔符，保留「全部材料都靠手划，机器不猜」；键盘导航本身（`use-desk-keyboard`）不变
