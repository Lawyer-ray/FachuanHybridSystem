## 一句话

| 之前 | 现在 |
|:--|:--|
| 手机上「＋ 新建项目」紧跟品牌标，右侧空一大片——因为承担右推的 `ml-auto` 挂在「AI 助手」按钮上，而那个按钮在 <640px 是 `hidden` | 右侧动作**整组**（检索 · AI · 新建 · 头像）由一个容器 `ml-auto` 右推，与内部按钮显隐无关 |

| 品牌全称「法穿 SI Copilot」占 94px，把「新建项目」的文字挤成纯图标 | ≤420px 只留「法穿」、副标收起；「新建项目」文字保留到 340px 才变纯图标 |

## 实测（Playwright 真 Chrome，360×800，`isMobile`）

| 元素 | 左缘 → 右缘（px） |
|:--|:--|
| 菜单 | 22 → 54 |
| 法穿（副标收起） | 62 → 96 |
| AI 助手（图标） | 130 → 162 |
| 全局检索（图标） | 166 → 198 |
| 新建项目（**带文字**） | 202 → 298 |
| 用户菜单 | 304 → 338 |

- 右侧内边距 22px → 338 + 22 = 360，**贴右**；`docScrollW = 360`（无横向溢出）
- 320 宽复测：新建项目自动变纯图标，右缘 298 / 视口 328，同样贴右
- 点「全局检索」→ 弹窗 328 宽落在 360 内；点「AI 助手」→ 面板 `fixed` 铺满 360

顺带确认：手机端汉堡菜单是 `fixed` 覆盖层（`left 0 → 360`），**不会挤压正文**
（`main` 宽度仍是 360）——此前截图里正文被挤成窄柱是页头自身的 flex 挤压，
已在 `v27.28.3` 修掉。
