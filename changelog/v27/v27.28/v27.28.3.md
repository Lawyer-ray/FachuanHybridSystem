# v27.28.3 · 窄屏（手机）排版修复：文字不再挤成一团、也不再互相压

> **版本判定**：§1.2 同一条线（`v27.28.x` 的页面交付）→ 第三位 +1。

## 怎么查的（不是凭感觉调）

用 Playwright 起**真 Chrome、真移动视口**（390 / 360 / 320 × 844，`isMobile+hasTouch`），
拿一枚开发用 JWT 直接读本机后端，逐页跑三件事：

1. **横向溢出**：元素右缘是否越过视口（跳过祖先可横向滚动的，比如程序链）；
2. **文字重叠**：叶子文本节点的包围盒是否真的相交（排除父子包含关系）；
3. **被压窄**：宽度 < 36px 却塞着 4 个字以上的文本。

覆盖 `/`、`/material-prep`、`/projects`、`/projects/:id`（诉讼 / 常法 / 专项各一）、
`/projects/:id/edit`、`/settings`，外加「记收款 / 传发票」两个弹窗。
查完再按定位结果改，改完**同一套脚本复跑**（最终 360 宽下 8 个路由 overflow=0）。

## 修了什么

| 位置 | 症状（实测） | 改法 |
|:--|:--|:--|
| 工作台列表行 `DealRow` | OA 编号与右侧「剩 N 天」**实测重叠 36×6px**：副行里 `truncate` 的 span 缺 `min-w-0`，flex 子项不会缩到内容宽以下，后面的编号被顶出容器 | 给该 span 补 `min-w-0`；OA 编号 `max-[560px]:hidden`（副行主角是「我方 vs 对方」） |
| 收件箱行 `InboxRowItem` | 主题只剩 13 个字、发送人只剩 5–6 个字：一行里塞了 图标 + 主题 + 徽标 + 时间 + 附件 + 「可转材料包」两块徽标 | 主题 `max-[520px]:line-clamp-2`（两行）；发送人补 `min-w-0`；「可转材料包 / 材料包」窄屏收起（点开抽屉同样看得到） |
| 预处理工具栏 `DeskToolbar` | 搜索框固定 `w-[200px]`，把整条工具栏顶出 20px 横向滚动 | 窄屏右侧那组独占一行，搜索框 `flex-1` |
| 页头 `DetailHeader` | 标题 `flex-1` 被四个按钮挤成窄柱（用户截图里标题折成七八行） | ≤680px 标题与动作**各占一整行**（`basis-full`） |
| 当事人节 `RailParties` | 法定代表人 / 电话 / 信用代码 / 地址四个 `nowrap` 片段挤在一行，18 位信用代码就占半行 | ≤680px 一项一行（地址保持可折） |
| 期限行 `DetailRail` | 到期文案 + 范围标签双 `nowrap`，在 320–360 宽度下顶出卡片 | 窄屏允许折行 |

## 已知取舍

- 收件箱「可转材料包 / 材料包」徽标在 ≤520px 隐藏：它们与「1 附件」挤在同一行右列，
  手机上一出现就把主题压成十来个字。能否转在点开的抽屉里同样标着，信息没丢。
- 程序链在手机上仍横向滚动（不折行）：折行会把「到哪了」的一屏叙事打散；
  真要折行得重设计这一块，不在本次范围。
