# v27.28.8 · 建案可回填收案日期（`CaseIn.start_date`）

> **版本判定**：§1.2 同一条线（`v27.28.7` 的新建案件）→ 第三位 +1。

## 一句话

| 之前 | 现在 |
|:--|:--|
| 新建案件一律用今天当收案日期：`CaseIn` 没有 `start_date`，`CaseUpdate` 也没有——建完就改不了 | 建案弹窗里有「收案日期」（默认今天，可改），二审/执行这类后续程序能填真实收案日 |

## 改了什么

**后端**

- `CaseIn` 增加 `start_date: date | None = None`。
- `CaseCommandService.create_case`：入参里 `start_date` 为 `None` 时**整键丢掉**，
  交给模型默认值（`date.today`）。不丢会撞 NOT NULL——`Case.objects.create(start_date=None)`
  直接 500，而「没填」的语义本来就是「用默认值」。
- 新增 2 条测试：给定日期真的落库（2026-07-07）、不填则等于今天。

**前端**

- `createCaseUnderContract` 增加 `startDate`（YYYY-MM-DD），只在有值时下发。
- `AddCaseDialog` 增加「收案日期」字段：默认本地今天（**不用 `toISOString()`**，
  那是 UTC，晚上会跳日），格式不对禁用提交；与「法院 / 仲裁机构」并排两列。
- 测试：默认值 = 今天、改成历史日期后请求里带的就是它。
