## 三个判断

1. **凭据落 agent home，不落库**。令牌要交给子进程（`QODER_CONFIG_DIR`），存库还得每轮解密写盘，多一份泄露面；CLI 自己会刷新它，库里的文字版迟早与磁盘版不一致。**磁盘是唯一真相**。
2. **判据是文件存在，不是跑 CLI 去问**。`<config>/.auth/user` 有就是登录了（实测：进行中只有 `machine_id` / `.credential-transaction`）。跑 CLI 要起进程 + 联网，而「联网失败」与「未登录」在输出上难以区分。
3. **状态落盘而不是放内存**。登录进程只在**一个** worker 上，轮询可能落到别的 worker；状态写进 `<agent home>/qoder/login/<id>.json` 后谁都能答。
