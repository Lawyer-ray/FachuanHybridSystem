# v27.9.1

前端 AI 助手（Copilot）**P0 批次改进**：对标开源 Agent 项目（OpenHands / LibreChat / LangGraph / Dify / LobeChat）做差距分析后，优先补齐「后端已有、前端未消费」的六条能力链路。本版全部为前端改动，无后端变化。

核心结论先行：后端的 steer 插话、后台任务、离线审批、排队提示、用量端点、多入口早已实现并有测试覆盖，但前端零消费——这是性价比最高的一批改进。

---

## 前端

#### 新功能 · AI 助手（P0 批次）

- **排队可见**（`store.ts` / `MessageList.tsx`）
  进程池满时后端会发 `activity{status:"queued", position:N}` 事件，此前被 store 的 `default: break` 静默丢弃，用户只能盯转圈。现在消息区顶部渲染「排队中 · 前方 N 人…」提示条（`position` 含自己，「前方人数」= N-1；N=1 时显示「即将开始」），收到首个推进事件（delta/thinking/tool_call/done/error）自动清除。

- **运行中插话（steer）与撤回**（`Composer.tsx` / `store.ts` / `api.ts`）
  流式期间输入框不再被「停止」独占：保持可用，Enter 即发送插话（`POST /sessions/{id}/steer`），在当前轮工具调用跑完后、下次模型调用前生效——想改方向不必停止重发、前功尽弃。输入框下方显示「已插话 N 条」计数，可整体撤回（`DELETE /sessions/{id}/queue`）。本轮已结束时后端返回 409，前端提示「本轮对话已结束，插话未送达」。

- **审批卡风险分级渲染 + 离线审批入口**（`ApprovalCard.tsx` / `CopilotPanel.tsx` / `types.ts`）
  - 卡片按后端四级风险分色：high 红（原有）、critical 深红 + 警示图标 + 「紧急」徽标、离线待审琥珀色 + 「后台任务」徽标。
  - **紧急级二次确认**：首次点击「同意」只解锁（按钮变「再次确认执行」并提示确认工具名），再次点击才真正提交；8 秒不动作自动收回——「删一条草稿」和「清空全库」不再长一个样。
  - **离线审批**：后台任务挂起的高危工具调用（无 SSE 连接、无人可问）此前用户永远看不到，只能等 7200s 超时。现在面板打开、每轮流结束、切会话后都会拉取 `GET /approvals/pending` 并渲染待审卡（倒计时按 OFFLINE_TIMEOUT=7200s 从服务端创建时间起算，与后端 `approval.py` 常量同步）；紧急级在线 900s 口径亦对齐。

- **后台任务入口与状态追踪**（`Composer.tsx` / `SessionSidebar.tsx` / `store.ts`）
  - Composer 新增时钟开关切换「后台运行」模式：提交走 `POST /agent/tasks`（适合「帮我梳理本案材料」这类要跑几分钟的长任务），受理后自动切到任务会话；提交后模式自动退出。
  - 侧边栏会话行显示 task_state 徽标（排队中/运行中/已完成/失败/已取消，五色区分）；列表中存在排队或运行中的任务时每 4s 轮询刷新，全部落定即停。
  - 任务会话的 `updated_at` 变化时自动重拉转录——后台跑完写入的「【后台任务完成】」通知消息与产出直接浮出，无需手动刷新。

- **断线后历史对齐**（`store.ts`）
  此前只有用户主动停止才重拉历史；网络中断/HTTP 错误路径直接白屏只剩「连接中断，请重试」。现在异常路径统一先重拉历史（服务端已把已流出部分落库，`truncated` 标记透传），再显示错误提示——半截回答不再丢失。

- **转录体验三件套**（`MessageList.tsx` / `CopilotPanel.tsx` / `copilot.css`）
  - 助手消息 hover 显示复制按钮（复制 Markdown 源码，成功打勾 1.5s；流式中的气泡不显示）。
  - 代码块语法高亮：接入 `rehype-highlight`（只处理标注了语言的代码块），亮/暗双主题手写 hljs 配色（不引入官方主题 CSS——那些是单主题的，暗色会洗掉）。
  - 面板头部显示当前会话实际使用的模型名（后端 `SessionOut.llm_model` 早已回报，前端类型未声明、从不显示）。

#### 优化 · 结构

- SSE 帧消费循环从 `store.ts` 抽出为 `streaming.ts`（reader 生命周期 + 事件路由），本轮流式处理器抽出 `turn-handlers.ts`（正文/思考/工具行/审批/排队/统计的状态更新工厂）——`store.ts` 从 452 行（超 450 硬红线）降至 339 行，单一职责更清晰。
- 前后端事件契约对齐：`types.ts` 补齐 `activity.position`、`approval_request.risk_level / needs_second_confirmation`、`AgentSession.origin / task_state / llm_model` 等此前缺失的字段（已出现过的漂移：activity 事件未消费、risk_level 未声明）。

#### 依赖变更

- 新增 `rehype-highlight@7.0.2`（代码块语法高亮，随 copilot 面板懒加载 chunk）。
