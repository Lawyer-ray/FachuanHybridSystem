## 三、这一版修了什么（8 条 P0 + 结构性清理）

### 3.1 空壳 Service 类 → 8 个端点必然 500（`56d8ca568`）

「静态方法下沉」清理把 `ImageRotationJobService` 的方法全搬到了模块级，**类体只剩注释**，
而 API 仍写 `ImageRotationJobService().list_jobs(...)` → `AttributeError` → 500。
8 个 `/api/v1/image-rotation/jobs*` 端点全中，且**全部带 `# pragma: no cover`**，
所以单测、覆盖率、结构测试三处都看不见。

- 改为直接调用模块级函数；同源的 `oa_filing` 空壳 `StampLookupService` + 两个死 helper + 未用 import 一并删除。
- 新增结构棘轮 `tests/ci/structure/test_no_empty_service_class.py`（无基类且无成员的 `*Service` 类，基线 0）。
- 说明为什么旧检查抓不到：`test_four_layer_architecture` 只看「还有没有那个装饰器」与包内
  `self._foo(...)`，跨层「API 调实例方法」不在其视野。

### 3.2 属主校验写了却没人传 `user`（IDOR，`56d8ca568`）

`get_job/list_jobs/get_job_detail/arun_ocr/delete_job` 早在安全审计 2026-10-19 就加了
`user=` 属主收敛，但 API 层**从未传** → 任意登录用户可按 job_id 读/改/删他人任务。
新增 `_actor(request)` 并在 6 处端点接通；回归测试断言「每个端点必然把当前 user 下传」。

### 3.3 `cast("DocumentTemplate" | None, …)` 运行期 TypeError（`56d8ca568`）

`cast` 的首参是**表达式**而非类型注解字符串，运行期求值 `"str" | None` 直接抛 `TypeError`，
补充协议模板匹配器根本没执行。原测试只「锁定现状」断言 TypeError，现已改为断言返回匹配到的模板。

### 3.4 默认配置里 4 个真实凭据 + 镜像烤进调试脚本（`eae5ea559`）

- 飞书 App Secret / 天眼查 Key / 企查查 Key / PaddleOCR Token 的默认值全部清空，
  删掉三处 `# pragma: allowlist secret`（它把密钥扫描静音了）。
- 新增 `tests/ci/structure/test_no_hardcoded_credentials.py`：`is_secret: True` 的默认值必须为空或占位符，
  且该目录禁止 allowlist 注释。
- `.dockerignore` 补 `devtools/`、`tests/`（Dockerfile 是 `COPY . .`，而注释早已写明禁止烤调试脚本）。

### 3.5 CI 的 mypy 棘轮开环（`c2f2739d4`）

旧写法 `mypy … 2>/dev/null | grep -c "error:" || true`：mypy 自己崩掉时 stderr 被丢弃、`grep -c` 得 0，
`0 <= 47` 直接绿。改为先抓全部输出、识别 `INTERNAL ERROR` / 插件实例化失败 / Traceback 即判红。
本地验证：正常口径 `errors=0`（绿）；故意去掉 `PYTHONPATH` → 判红并 exit 1。

### 3.6 automation 五条 P0（`fix(automation,documents)`）

孤儿文件清理加 `dry_run` + 时效 + 引用白名单 + `resolve()` 归一；文书引用删掉「取同目录最新文件」兜底
（注释自陈曾造成 57/63 条短信错配）；重新绑定案件改软解绑（不再物理删 CaseLog 与附件）；
`smoke_check` 的 `migrate` 变成显式开关、口令缺失即 `CommandError`、非 test 库需 `--yes`；
`submit_sms` 加共享密钥过渡闸门。六个测试文件、65 项通过。

### 3.7 `document_recognition` 两处 NOT NULL 裸写 None

识别不出案号时把 `None` 写进 NOT NULL 的 `case_number` → `IntegrityError`，任务由 SUCCESS 变 FAILED；
重跑失败任务时把 `error_message` 置 `None` → 接口 500。两处均改为空串（与同文件既有正确写法同口径），
`tests/ci/unit/document_recognition/` 全目录通过。

### 3.8 棘轮自证：这一版自己的改动被棘轮抓了两次

worker 首版修复在 `services/` 里新加了一个静态方法装饰器、并写了 2 个零断言测试，
被 `test_four_layer_architecture` / `test_test_quality_ratchet` 当场判红（12 > 11、8 > 6），
已按棘轮改正（改成模块级函数、补可失败断言）。**这说明棘轮是通电的**，不是摆设。
