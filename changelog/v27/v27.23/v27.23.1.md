### 3. P1 修复（20 条，`TECH-DEBT.md` §F/§G 全部结清）

`/compact` 与在飞对话并写同一 session 文件（→ 409）· `ask_user` 跨 worker 唤不醒（→ 事件快路径 + 0.2s 轮询 Redis）·
`cluster.lanes` 字段不存在导致「立场相同」永不输出 · RPC `_pending` 双键互相覆盖（→ id 索引 + command FIFO）·
模块级 `asyncio.Lock` 跨 loop（→ 按 loop 懒建）· 三个后端 `_results` 无界（→ `BoundedResultStore` 256 封顶）·
槽位/栏数上限三处各一份（→ 新增 `chat/config.py` 单源）· `record_step` 把 `started_at` 抹成 None ·
抽帧「先删后写」无事务（→ 先算后换）· `_build_mcp_kwargs` 无条件注入 `case_id`（→ 按签名过滤）·
`confirm_segments` 在 `atomic` 内派发导出任务（→ `on_commit`）· MCP docstring 教 `by_page`（真值 `page_split`）·
`retry_analysis` 先删映射再调 LLM（→ 先算后换，且只删旧批 id）· `bind_textin_job` 零调用点（→ 调度侧补落库绑定）·
`_require_admin(None)` 错误文案误导 + 临时模板残留；
`mcp_server` 搜狗跳转判定对**任意网页**生效（普通页里一个 `http-equiv` + `URL=` 就把另一份文档当结果返回）；
`mcp_server` refresh token 轮换被丢弃（settings 开了 `ROTATE_REFRESH_TOKENS`，下次刷新必 401 → 每几分钟无谓重登）；
`document_parsing` Admin 上传建记录漏 `created_by`（NULL 归属对全所非管理员可见）。
