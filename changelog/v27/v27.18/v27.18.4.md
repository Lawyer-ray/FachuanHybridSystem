## 后端

#### 修复

- **confirm 后 `content_md` 整体错位一格、末段拿空串**（P0-3，确定性 bug）
  - 根因：自动分段产物 `segments_md.json` 按 0 基 order 存，`confirm_segments` 用 1 基重建 DB 记录
    却**只写 `segments.json`、从不重写 md**，读取侧按 order join → 即使律师什么都没改也错位。
    MCP `confirm_pdf_split` 同路径，agent 确认后读到的正文直接污染起草输入。
  - 修法按报告 §9.3/§10.1 定论：**按用户确认后的新页区间重建 md**（读 `pages.json` →
    `build_segments_markdown` → 重算一致性 flags），与自动分段同一条重建路径，天然覆盖
    「合并/拆分/改页区间/改名/乱序」。不是只改 order 基址（那样用户一调整分段仍然错）。
  - 旧任务无 `pages.json` 时按**页区间重叠**重新配对旧 md（页→条目倒排索引），配不上留空串并
    `logger.warning`；部分重叠时**丢弃页锚点**（旧偏移对拼接后的新字符串已失效，留着比没有更糟）。
  - 新增 21 条 confirm 测试，含**真的调整过分段**的场景（报告 §4 的验收口径）。

- **两阶段 + auto 任务 `positioned` 恒空**（P0-5）：`segment_stage` 原用 `job.cloud_backend`
  （容灾偏好 `"auto"` → `resolve_bbox_unit` 返回 unknown → 定位框整批丢弃），而单任务入口用的是
  取字 summary 里的实际平台——两入口口径不一致。改为读取字阶段落盘的 `extract_summary.json`
  的 `ocr_provider`，拿不到时按逐页 `source_method` 推断并 warning，**不退回 auto**。
  连带：`run_extract_stage` 落盘整份取字 summary（原先只落 pages + page_quality，观测字段全丢）；
  `resolve_bbox_unit` 认 `local`→千分比（P2-5 后兜底路径实为 VL 云 API，版面按 1000×1000 写出，
  认成 unknown 会把刚拿到的坐标整批丢掉）。

- **印章清洗贪婪正则吞掉真实正文**（本轮新发现的内容丢失回归，比噪声更严重）
  - `strip_stamp_boilerplate_lines` 的 `经办人[:：][^\n]*` 贪婪到行尾，取字层把混合行**改写成
    cleaned**，实测会吞掉「经办人：某某 某某根据《物权法》…准予登记，颁发此证」（整段权证正文）、
    FATCA 尽职调查声明、「国土资源部监制」、材料标题等 **20 行**。
  - 修法：**统计口径与清洗口径分离**——字数统计仍用原判据（60/200 字页面分类阈值按它校准，
    零漂移）；正文清洗改「标签+冒号+空白」+ **逐行 all-or-nothing**：剥掉标记后每个 token 都是
    人名形态短词才整行删，否则只剔字面量固定短语，经办人/人名/正文一字不动。
  - 效果：取字层救回 **107 字**、全 164 页口径 **807 字**（含 p106 合同条款 266 字）；
    离线保真复核「删除不可归因为套话 0 行、改写超出只剔短语 0 行」。
  - md 重建层复用同一判据并加**逐 token 残留复核**；人名形态守卫收敛为
    `page_quality.is_name_token` 单一公开定义（两份定义一漂移就会真删正文）。

- **首次 extract 无阶段预算 + 分段预算不够单批最坏耗时**（P1-8 / P2-7）：首次提交改调
  `submit_extract_stage`（20 分钟预算，原先吃集群默认 600s）；segment 阶段 20→**35 分钟**，
  依据 `DEFAULT_BATCH_RETRY=2 × 480s 墙 = 1440s` 已超原 1200s（与并行度无关，一批抖动就够硬杀
  整阶段），新值 = 1440 + 480（尾部一轮余量）+ 180（合并/一致性/md/落盘）。刻意不到 45 分钟：
  多批同时耗尽重试 = LLM 整体不可用，就该被杀并整轮规则兜底。测试从常量现算，改小即红。

- **summary 谎报 LLM 分段**（P1-9）：单批降级规则引擎时仍写 `segment_backend="llm"`，前端
  `segmentBackendOf` 读到 llm 就不提示复核——消费方存在但喂给它的值是错的。改为按批统计写
  `llm`/`mixed`/`rule` 并附批数；≤25 页单批路径补重试（原先一次非法 JSON 整轮降级，小卷宗反而更脆弱）。

- **GFM 表格合并单元格金额错列**（P1-1，诉请金额的生命线）：`_html_table_to_markdown` 原按
  「每行 td 个数」补空列，改为复用现成 rowspan/colspan 网格占位算法，按真实网格列位置放文字
  （colspan 落锚点列、其余覆盖列留空）。网格算法平移到新模块 `md_table.py`，定位框行为不变。

- **首行数据被当 GFM 表头**（P1-7）：原无条件 `header, *body = normalized`。改为 `<th>` /
  短纯标签含表头词 / 全短非数值标签才当表头，否则插空表头行、数据一行不丢；三条否决防
  「字段名:值」被当列名（长数字串、首格纯数字、半数以上长文本格）。实测 43 张表 → 9 张。

- **md 净化三件套**（P1-6）：① 原始 HTML 泄漏（`<img>/<div>` 写进 page.text 与单元格）按
  **已知标签名单**剥壳（不用 `<[^>]+>` 通吃，避免吞掉「金额<100万」），img 去除不编占位；
  ② 注入段名与文档自身首标题归一化后相等则不重复注入；③ >30 列怪兽表降级为按行纯文本
  （实测 p151 745 列）+ 年份交叉校验（表格坏年份≥60% 且样本≥8，且同页纯文本独立合理才降级）。

- **噪声清洗**（P1-4）：表内页脚行（「打印日期:… 第2页」）剔除，含纯文本夹带的 GFM 行；
  跨页重复短行（≤30 字、≥3 页且 ≥50% 页）过滤，条款号/金额日期账号/表格行/标题行一律保护；
  文本层与兜底页接上现成 `clean_page_artifacts`（原先零过滤，判决书页眉案号每页混入）；
  MinerU `_is_repeated_header` 接到 **layout 侧**（原先只服务 text 路径），把误标 text 的重复
  页眉改回 header 类型而非删块，且**必须在行框合并之后**改（否则该页之后所有行框错位一格）。

- **续页合并双向失效**（P2-2，两条独立风险分别修）：① 误并——`_clause_number` 只认 X.Y/第X条，
  「一、/1、」触发合并但序号校验被跳过；改为统一返回（编号体系, 序号），任一侧解析不出或
  体系不同**就不合并**。② 漏并——末页最后一个 `\d+\.\d+` 把金额 50000.00/日期 2024.01 当条款号；
  改为只扫行首候选 + 整数≤2 位 + 小数≤2 位 + 单位后缀排除（元/万元/平方米/㎡/%）。
  ③ 合并后 40 页上限 → **80 页**（≈3 个 25 页批 + 余量），跨批长合同不再永不合并。

- **批首无左上下文 + LLM 摘要剥光换行**（P1-3 / P1-2）：`win_start = max(1, own_start - overlap)`，
  prompt 逐页标「·上下文」并明确「前 K 页不要产出分段」，消除每 25 页一个的结构性断点；
  摘要改用 `page.text` 的**非空行**（首 10 行 + 尾 6 行 + 中略标注，单行上限 120 字），
  让「落款/此致/具状人」等行级收尾判据真正可用。连带修掉自己引入的回归：规则降级批原把
  上下文页一起喂进规则引擎 → 首段起点落在上下文区被丢弃 → 负责区间开头成覆盖缺口。

- **缓存来源防伪**（P2-6）：容灾缓存档案名记首选平台而非实际平台，命中时坐标系被污染
  （TextIn 绝对坐标被套 MinerU 千分比）。改为命中时读缓存内 `source_method` 恢复真实来源；
  本轮没调云端时按缓存恢复出的平台报 `ocr_provider`（多平台混用取多数 + warning）。

- **起草侧二次抽取把预处理成果整条丢弃**（报告 §3.C.0）：扫描页只要有 ≥20 字印章语就**永不 OCR**
  → 改「页文本 <20 字」**或**「整页图像覆盖率 ≥0.5 且文字 <200」双判据（`page.get_image_info()`
  算覆盖率），正常电子页不白 OCR；检索片段 `c.text[:500]` → `EVIDENCE_EXCERPT_CHARS=1500`
  （与 chunk 粒度对齐、top_k=5 约 4-5k token 可控、条款不拦腰断），digest 两处 + draft 一处同改。

## 前端

#### 新功能

- **右栏原始 Markdown 视图 + 轻量渲染**（P3-2）：律师此前看不到 md 结构（有 blocks 时只渲染纯文本行），
  而表格/标题恰是 OCR 最易错处。新增 `SegmentMarkdownView.tsx`（react-markdown + remark-gfm，

- **材料包级识别选项**（P3-1 / P3-3）：`DraftState.recognition` 按包持久化版面策略与引擎勾选，
  换包不继承、重开同一包保留；新增 `AutoSplitSettings.tsx` 明示计费。
  **计费默认值变更**：**新建包**默认开双引擎（`mineru + paddleocr_vl`，同一份 PDF 付两次云端费），
  设置菜单给**一键关闭**；存量草稿无 `recognition` 键时不套用本默认（避免老包突然双倍计费）。

#### 修复

- **块级编辑不打 manualEdit，律师核对成果被重跑静默抹掉**（P0-4，确定性 bug）：
  `setSegmentBlockText` 改了 md 却没走 `markManualEdit`（同文件 `updateSegmentMd` 正确用了），
  重跑冲突检测按 `manualEdit.md` 判断 → 引擎分歧「采用/修改」走的正是这条路。
  连带修「`indexOf(oldText)` 首次匹配替换、找不到原文时 md 静默留旧值」的两视图漂移。
- **切段/并段丢 md**（P2-1）：`splitSegment` 头段原样保留整段 md（含已切出去页的文字→污染）、
  尾段不带 md；`mergeSegment` 被并段 md 直接丢弃；`selection.ts` 三个运算同样不带 md。
  改为按后端 `page_spans` **精确**按页搬运（新增 `draft/md-pages.ts`：越界/非法偏移一律丢弃，
  缺锚点时退到 blocks 页号近似），切/并后打 manualEdit。
- **规则分段计数少报**：`ruleSegmentCountOf` 只数 `source_method === 'rule'`，而规则引擎实际产出
  6 种取值（rule/layout_title/rule_weak_only/rule_adjacent_start/gap_fill/rule_merged_adjacent）。
  改**排除法**判据（排除 llm / manual / page_split），人工段不被误报成规则段；并支持后端新的 `mixed`。
- **分歧抽屉把姓名聚类误标「疑似错字」**：聚类判据**没有**「哪个写法对」的证据，沿用错字标签会让
  律师把两个真人合并成一个。按 `kind` 三分支：`entity_cluster`→「姓名多写法候选／请核对是否同一人」
  （**刻意不提次数、不说哪个对**）、`id_malformed`→「证件号结构异常」、`frequency` 原样。
  连带修隐藏缺口：`draft/quality.ts` 的 `readInconsistencies` **逐键重建对象**会把后端新加的 `kind`
  静默丢掉（不修则本项完全无效）；左栏入口 tooltip 的 blanket「（疑似错字）」→「（待核对」。
- **图片旁路不按坐标排序**（P3-4）：`blocksToMarkdown` 原只是 `join('\n')`，改为用 OcrBlock 坐标
  y→x 行聚类重建阅读顺序。
- **登出丢最后 450ms 防抖内的编辑**（P3-5）：登出前先 flush 草稿。
