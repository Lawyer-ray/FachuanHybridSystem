# v27.1.13

前后端依赖例行升级：后端 uv lock 全量刷新（直接依赖 + 传递依赖约 60 项），前端 pnpm 在 semver 范围内升级。无业务代码变更。

## 后端

#### 依赖变更

- **直接依赖升级**：pikepdf 10.13.0.post1 → 10.15.0；huggingface-hub 1.32.0 → 2.0.0（本项目仅使用 `hf_hub_download` 的 `repo_id/filename/revision/local_dir` 基础参数，v2 移除的 `resume_download` 未使用，兼容）
- **MCP SDK 锁定 1.x**：`mcp[cli]` 升至 1.30.0 并新增 `<2` 上限——mcp 2.0 为协议级破坏性变更（stateless spec、`FastMCP` 重命名为 `MCPServer`），`mcp_server/` 与 `enterprise_data` 的 `ClientSession` 用法需专项迁移，不适合随例行升级合入
- **dev/test 工具链**：isort 9.0.1 → 9.0.2；ruff 0.16.8 → 0.16.9；hypothesis 6.168.0 → 6.168.3
- **传递依赖刷新**（`uv lock --upgrade`，均为约束内解析）：openai 3.20.0、pydantic-ai 2.51.0、sentry-sdk 2.71.0、starlette 1.7.0、boto3 1.43.104、authlib 1.8.0、pyjwt 2.15.1、urllib3 2.8.0、watchfiles 1.3.0、google-auth 2.59.0、filelock 4.0.6、ujson 6.0.0、logfire 5.1.1 等
