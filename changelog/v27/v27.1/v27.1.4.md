# v27.1.4

本版本是**前端的整体质量治理版本**，源于一次两轮代码审计（第一轮全量逐行审查，第二轮对每个结论读码复核 + 工具链验证）。修复审计确认的 **11 个功能缺陷**——包括日历切月不取数、全局检索键盘回车不跳转、飞书扫码失败后无法重试、多列拆分剪刀按钮不可见、「已归案」印章不显示、状态背景色整体失效等；同时统一错误处理 / 数据获取 / query key 等约定口径，并清理约 1100 行死代码与死配置。**仅前端改动，后端无任何变更，无数据库迁移。**

## 前端

#### 修复

- 日历：**修复切月永远显示空日历**。视图月此前困在 CalendarPanel 内部 state，而取数 query 固定只请求「今天所在月」；现视图月上提 HomePage 持有，切月即请求当月，`keepPreviousData` 避免切月闪空
- 日历：修复手机端抽屉「＋ 新增」点击只静默刷新不开弹窗（`onAdd` 实际传的是保存后刷新回调）；新增弹窗上提 HomePage，日历空白格与抽屉共用
- 日历：格内「+N 更多」补 `data-calendar-more` 并纳入点击守卫，不再误触「新增安排」弹窗
- 全局检索：**修复键盘回车选中结果不跳转**（`pick()` 此前只关面板不导航），键盘与鼠标行为一致
- 登录：**修复飞书 SDK 加载失败后「重新加载」永久失效**——rejected promise 被缓存在 `window` 上且从不清理，现失败即清除；boot 各 await 后校验组件仍挂载，消除卸载后 setState 与 StrictMode 双挂载副作用
- 材料预处理：**修复多列模式「切开」剪刀按钮永远不可见**（多列包裹层缺 `group` 类，`group-hover` 恒不生效，且隐形按钮仍可误点）
- 材料预处理：**修复「已归案」印章永不显示**（CSS 触发选择器 `.mp-packet.stamped .mp-stamp` 与实际 DOM 不匹配，改为 `.mp-stamp.stamped`）
- 全局：**修复状态背景色类整体失效**——`@theme` 缺少 `--color-status-*-bg` 五项映射，`bg-status-red-bg` 等类不生成任何 CSS，收件箱热消息、「今天」格子、解析错误提示块此前全部白底
- 材料预处理阅读器：修复归案弹窗打开时按 Esc 连整个阅读器一起关闭（`assignOpen` 提升进 store，Esc 逐级退出能感知最上层手写模态）
- 材料预处理阅读器：修复快速连点两个材料包时详情张冠李戴（`store.open()` 响应回来校验 openId）；取字拖框判定改走 ref，move/up 同帧批处理不再丢矩形；照片页 `objectUrl` 卸载竞态泄漏补齐回收
- 首页：QuickAdd 回车绕过 busy 防护可双提交，补防重入闸；DOC 转 DOCX 轮询补 2s 节奏常量与 5 分钟上限（任务卡死不再无限轮询）；`createConverterJob` 兜底业务失败，不再拿 `undefined` 当任务 id 去轮询
- 登录：错误文案区分 **401（用户名或密码错误）/ 网络 / 超时**，不再把 500、断网一律报成密码错误；回调页失败态由显式状态机驱动，不再用「message 是否等于初值」派生

#### 优化

- 错误文案提取统一：`errMessage` 提升到 `lib/errors`（新增 Django `detail` 分支、超时文案可定制），首页工具卡、新增弹窗、登录共 6 处同一实现；QuickAdd 不再吞掉后端 message
- 数据获取收进 react-query：登录页「已启用登录方式」、导航栏 `/organization/me` 补拉用户名改为 `useQuery`（带缓存，此前手写 effect 每次进页重发且失败无痕）
- 规范对齐：移除 `use-inbox` 4 处 `onError` 内无效 `throw`（方向与规范相反，异常无人接住）；query key 收口为 `calendarKeys` / `HOME_INBOX_KEY` / `REMINDER_TYPES_KEY` / `CONVERT_TEMPLATES_KEY`，不再散落字符串字面量
- 类型如实化：`draft_state` 标注「可能为空对象」（后端未拆分时返回 `{}`）；`createReminder` 关联字段映射改 `Record<TargetType, …>` 穷举，拼错编译期即报；`User` 去掉索引签名；`SocialCallbackPage` 状态机化
- API 基址统一：默认值由写死的 `http://localhost:8002/api/v1` 改为相对路径 `/api/v1`（dev 走 Vite 代理、生产同源部署均成立，与社交登录的同源 cookie 约定一致）；`localStorage` 的 `api_base_url` 覆盖仍优先
- 阅读器内源文件重命名以 AlertDialog 替代原生 `prompt()`，与其他确认流风格统一；Flow 双分支 15 行 PageCell props 收敛为共用工厂；`draft/selection` 三处扁平序映射提取 `flatIndexesOf`
- 工程口径：测试文件纳入 `tsc -b` 类型检查（此前被 exclude 游离于类型检查外）；`test` script 改 `vitest run`（管道/CI 下不再静默）；sonner toast 固定 light，消除「系统暗色 → toast 变暗而页面仍亮」的割裂（暗色令牌保留，待接入）

#### 移除

- 删除 17 个零引用的 shadcn ui 组件（avatar/badge/card/checkbox/collapsible/label/popover/progress/scroll-area/select/separator/sheet/skeleton/switch/table/tabs/tooltip），后续需要可用 shadcn CLI 一键重装
- 删除零引用死代码：与后端契约矛盾的 `social-types.ts` 旧类型、`home/errors.ts`（并入 lib）、`domain.ts` 的 `timeOfDay`、`draft` 的 `rangeLabel` 等死导出、`lib/pdf.ts` 的 `renderPdfPageBlob`
- 清理死配置：`vite.config.ts` manualChunks 里 10 个未安装包（framer-motion/zod/recharts/react-markdown/@dnd-kit 等）的死规则；tsconfig 根不生效的 `paths`；vitest coverage 指向不存在文件的排除项；index.css 零使用的 glow / hljs / ScrollArea 选择器 / `popover-in` / `3xl` 断点
- 移除「全部日程 →」「全部 →」「全部工具 →」三处无 onClick 的假链接；`auth/index.ts` 出口收口为实际消费方（页面组件 + useAuth）

#### 依赖变更

- 移除 9 个未使用依赖：`next-themes`、`radix-ui`（元包，统一为 `@radix-ui/react-*` 单包）、`@tailwindcss/typography`，及 6 个仅被已删组件使用的 `@radix-ui/react-*`（avatar/label/progress/scroll-area/select/separator/tabs/tooltip 中零引用者）
- 保留依赖无版本变更；`pnpm-lock.yaml` 相应收敛

## 说明

- 本版本**仅前端改动**，后端无变更、**不含数据库迁移**，部署无需执行 `migrate`
- 改动依据：两轮代码审计报告（第二轮对第一轮全部功能级结论逐行复核，并新增 `tsc -b` / eslint / vitest / build 四项工具链验证）；全部功能级结论经复核属实，其中 1 处计数勘误（无效 onError 为 4 处非 3 处）、2 处严重度下调
- 全量验证通过：`tsc -b`（含测试文件）、ESLint 0 错误、vitest 48 用例、`vite build`；状态色修复已在 dist 产物确认生成
- **已知遗留（本次有意不处理）**：`setPackStatusRemote` 读-改-写竞态需后端提供轻量状态端点；二维码 `expires_in` 过期自动刷新、删除页撤销为功能增强；`app/` 路由层与路由级代码分割为架构演进项，留待专项
- `VITE_API_BASE_URL` 默认值语义变化：此前前端默认直连 `http://localhost:8002`，现默认走同源 `/api/v1`（dev 由 Vite 代理转发）。使用环境变量或 `localStorage` 覆盖的部署不受影响
