# v27.1.8

本版本为「记一笔」文书识别弹窗做了一轮完整的体验升级（摘要卡、扫描动画、智能默认、左右分屏原文预览、两级宽度拖拽），并新增日历事项勾选完成（前后端 + ICS 三端口径统一）。**后端含一次加列迁移（reminders 0009：is_completed/completed_at/completed_by；合并部署到其他环境时需 migrate）。**

## 前端

#### 新功能

- **识别等待态重设计**：堆叠双纸张扫描场景（错位衬纸 + 模拟文字檀纸条 + 蓝色扫描线往返 + 图标呼吸）+「上传 → 识别 → 人工确认」三步进度（完成绿勾、激活段蓝绿渐变流光、激活步骤柔光圈、hint 呼吸圆点）
- **识别结果摘要卡**：文书类型按色标签、案号、置信度、引擎·提取方式（`vlm=AI 视觉`）；联系人/地址两行展示（后端读时提取）；「查看文书」预览入口；降级改琥珀徽章「降级识别·建议核对」
- **左右分屏原文预览**（≥1024px）：左栏文书原文（PDF=iframe 浏览器原生查看器 / 图片=img，加载态淡入、栏头「新窗口」兜底）与右侧确认步骤独立滚动；弹窗加高至 88vh、header/footer 固定
- **两级宽度拖拽**：栏间分隔条调原文栏宽（32–70%）、弹窗右缘手柄调整体宽（960px–视口-32px），均 localStorage 记忆；拖拽中全局列光标/禁选中/预览层防 iframe 吞事件
- **弹窗默认自适应视口宽**：分屏态默认 `min(95vw, 视口-48px)` 接近网页边缘（去 1120px 固定上限）——默认开最大，人工只需调小
- **智能默认（纯函数 + vitest）**：低置信候选（<0.5）默认不勾并标「低置信·请核对」虚线行；推荐案件唯一高分（≥80 且领先次位 ≥15 分）自动预选并标注，可一键换选
- **日历事项可勾选完成**：日历格/详情弹窗/手机抽屉/今日卡四处勾选，完成态落库；今日卡原纯本地假勾选改为真实状态并显示「n 待办 · 已完成 n/m」

#### 修复

- **查看文书跳回首页**：`file_url` 为后端相对路径 `/media/...`，Vite 未代理该前缀、打到 SPA 兜底路由被重定向；补 `/media` 代理 + 前端统一经 `resolveMediaUrl` 解析（兼容自定义 API 地址的宿主环境）
- **案件搜索撑爆弹窗**：搜索结果原平铺在文档流里，grid item 无 `min-w-0` 使长案件名 truncate 失效、弹窗超宽横向滚动；改为输入框正下方绝对定位浮层（248px 内滚、计数头、失焦收起）
- **反复拉宽变窄后弹窗卡窄**：宽度记忆曾随窗口 resize 被破坏性改写；改为期望宽度与视口钳制分离（渲染时派生 `min(期望, 视口-32)`，存储值不丢）；窄屏（<1024px）记忆宽度只在 lg 断点生效，单栏永远 560px

## 后端

#### 新功能

- **提醒完成态（日历勾选完成的底座）**：`Reminder` 新增 `is_completed` / `completed_at` / `completed_by`（迁移 0009，三字段一组不变量仅经 `ReminderService.set_completed` 维护，逐条 save 保留 simple_history 审计）；新增 `POST /reminders/complete` 批量端点（合并事件一次原子更新全部 member_ids）
- 日历口径统一：合并事件完成 = 全部成员完成；已完成不再标逾期、同日沉底；`today` / `deadline_in_7days` 只数未完成并新增 `today_done`，`month_court` 保持全量
- ICS 导出与订阅：已完成事件 `STATUS:COMPLETED`；Django admin 日历删除线 + 降透明样式、列表加 `is_completed` 筛选与完成状态只读区

#### 依赖变更

无（pyobjc-framework-Vision 平台标记依赖见 v27.1.7）。
