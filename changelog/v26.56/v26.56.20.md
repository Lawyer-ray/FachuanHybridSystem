# v26.56.20

> 分支：`feat/readme-paid-deployment`

## 后端

### 新功能

#### feat(core): AI 平台多 Key 并发 + 多平台配置

- 新增 `LLMProvider` 模型与「AI 平台」管理页（`/admin/core/llmprovider/`），支持任意数量的 OpenAI-compatible 平台（律所自建 vLLM、小米、Moonshot 等）
- 每个平台支持配置**多个 API Key**，自动轮询分配；Key 失败后进入 30 秒冷却并自动切换下一个
- 支持设置**每 Key 并发上限**（默认 3，0 表示不限制），配合多 Key 精细控制并发
- 按**模型名自动路由平台**：请求模型匹配到对应平台；未匹配时使用优先级最高的启用平台
- **向量模型独立配置**：每个平台单独填写向量模型；留空表示该平台不启用向量能力（不再回退默认模型，避免用对话模型做向量化报错）
- 「AI 平台」列表页新增「**初始化 AI 服务**」按钮：幂等写入一条基础平台（律所 kimi 默认地址 + `kimi26`），已存在平台时不覆盖
- AI 能力统一在「AI 平台」管理，移除「系统配置」下 `OPENAI_COMPATIBLE_*` 等 AI 服务项
- 模型列表（`/models`）自动并入各平台注册的模型，前端可选
- 配置改动经 `LLMProviderService` 进程内 TTL 缓存（300s），Admin 保存/删除后立即失效

### 优化

- `INSTALL.md` 新增「AI 平台配置（多 Key 并发 / 多平台）」章节，说明多平台与多 Key 的配置方式
