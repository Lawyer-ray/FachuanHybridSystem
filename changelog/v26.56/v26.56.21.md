# v26.56.21

> 分支：`feat/readme-paid-deployment`

## 后端

### 新功能

#### feat(document_parsing): 解析平台多凭证并发 + 多服务配置

- 新增 `DocumentParseProvider` 模型与「解析平台」管理页（`/admin/core/documentparseprovider/`），集中管理文档解析服务配置，不再使用「系统配置」下的文档解析项
- 支持**多凭证并发**：TextinParse 每行填一组 `app_id|secret_code`，MinerU 每行填一个 API Key，多凭证自动轮询分配
- 凭证失败后进入 **30 秒冷却并自动切换到下一个**；支持设置**每凭证并发上限**（默认 3，`0` 表示不限制）
- 新增全局 `CredentialPool` 凭证池（线程安全，跨任务共享、按平台隔离），复用 AI 平台的多 Key 并发 + 失败冷却机制
- 后端接入凭证池：`TextinBackend` 动态按凭证构建 SDK 客户端解析 `app_id|secret_code`；`MinerU` 移除类级 Key 轮转、改由凭证池管理
- `ParserFactory` 支持 `backend="auto"` 按**优先级自动选择启用解析平台**；未配置任何平台时自动回退本地解析（`local`）
- 新增 `ParseProviderService` 进程内 TTL 缓存（300s）读取平台配置；Admin 保存/删除后立即失效
- 数据迁移：将旧「系统配置」`MINERU_API_KEY`、`TEXTIN_APP_ID/SECRET_CODE`、`DOCUMENT_PARSING_BACKEND` 迁移到「解析平台」记录并删除旧键；「系统配置」初始化按钮跳过解析配置

### 移除

- 移除「系统配置」下的 `MINERU_API_KEY`、`TEXTIN_APP_ID`、`TEXTIN_SECRET_CODE`、`DOCUMENT_PARSING_BACKEND` 等项目及文档解析配置定义（`_system_config_data/_document_parsing_configs.py`）

### 优化

- `INSTALL.md` 新增「文档解析平台配置（多凭证并发）」章节，说明 TextinParse 多凭证、MinerU 多 Key 与自动选择后端方式
