# v26.56.16

> 分支：`chore/deps/upgrade-python`（移动端 Admin 抽屉侧边栏 + E2E 测试基建）

## 后端

### 新功能

#### feat(admin): 移动端新增抽屉式侧边栏菜单

- 修复手机端无法查看 Admin 导航菜单的问题：原生 `nav_sidebar.css` 在 ≤767px 时隐藏侧边栏，而项目首页又固定重定向到日历，导致手机用户无法切换到合同/案件等模块
- 新增 `mobile_nav_drawer.css` / `mobile_nav_drawer.js`（apps/core 静态文件）：移动端显示汉堡按钮，点击从左侧滑出 280px 抽屉侧边栏，带遮罩层，点击遮罩、Escape 或侧边栏内链接均可关闭
- 通过 `base_site.html` 挂载汉堡按钮（含 aria-expanded/aria-controls 无障碍属性），CSS 在原生样式之后引入以覆盖其隐藏规则；不改动 Django 原生桌面侧边栏行为与 localStorage 状态

### 测试

#### test(e2e): 新增移动端导航 E2E 用例并修复陈旧断言

- 新增 4 个移动端用例：汉堡按钮桌面端隐藏、抽屉展开且包含「办案/其他工具」菜单、点击遮罩关闭、抽屉内点击「办案」可跳转办案 Hub（本次修复的核心场景）
- 修正 `test_sidebar_has_expected_sections` 等用例中对「提醒」的陈旧断言：reminders app 在 `_HIDDEN_APP_LABELS` 中被有意隐藏（日历即首页），改为断言实际可见的虚拟菜单
- 修复遮罩点击用例：遮罩几何中心落在 280px 侧边栏内部会被内容拦截，改为显式点击侧边栏右侧区域

### 依赖变更

- 新增 `pytest-playwright>=0.8.0`（解析为 0.9.0，兼容 pytest 9）到 test 依赖组，提供 `page` / `admin_page` fixture；此前 E2E 套件因缺少该插件在本机无法运行
