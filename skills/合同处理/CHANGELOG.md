# Changelog - 合同处理工作流

所有对此工作流的更改都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，

## [1.2.0] - 2026-08-01

### 新增

- 合同审查 skill v1.0.0
  - 7 步审查流程（客户识别 → 全文通读 → 效力审查 → 条款审查 → 风险评估 → 交互确认 → 输出）
  - 效力审查优先 + 正反两面法 + 五道门条款审查
  - 六维风险评估 + 15 类风险标签
  - 交互确认机制（先列出发现，用户确认后再输出）
  - 修订模式与批注混用，以 "Lawyer" 身份标注
  - 输出：`{原文件名}[修订版]V1_{YYYYMMDD}.docx`

### 修复

- 所有 skill README 中的 `pip install` 改为 `uv sync` 说明
