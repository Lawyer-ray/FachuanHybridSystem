# 合同审查 Skill (V1.0)

专业合同审查，面向中国民商事合同。审查报告以 .docx 格式输出。

> ⚠️ 本工具不构成法律意见，仅供律师作为审查辅助参考。律师分析利弊，客户做决定。

## 触发条件

- 用户说"审查合同""审核合同""合同风险分析""帮我看看这个合同"
- 用户上传 .docx/.pdf 合同文件并要求审查
- 用户说 `/contract-review` 或 `/合同审查`
- 用户说 `review contract`

## 输入

接受以下输入格式：

| 格式 | 处理方式 |
|------|----------|
| .docx 文件路径 | 直接读取 |
| .pdf 文件路径 | 转换为 .docx 后读取（调用 doc转docx skill） |
| 粘贴的合同文本 | 直接分析 |
| .doc 文件路径 | 先调用 doc转docx 转换 |

## 审查流程（7 步有状态工作流）

### Step 0 — 客户识别与规则加载

1. **识别客户**（按优先级）：
   - 用户直接告知
   - 匹配合同当事人与 workspace 中的客户规则
   - 从文件路径提取
   - 询问用户

2. **加载客户偏好**：如有 `client-rules/` 配置，加载该客户的审查偏好（如关注重点、风险容忍度、修订风格）

### Step 1 — 建立审查状态

记录以下信息到审查上下文：

| 字段 | 说明 |
|------|------|
| 源文件 | 文件路径、格式 |
| 客户 | 客户名称 |
| 起草方 | 我方起草 / 对方起草 / 第三方模板 |
| 交易结构 | 简述交易类型和主要安排 |
| 立场 | 我方在合同中的角色（甲方/乙方/买方/卖方等） |
| 风险预分类 | 8 维度预打分（1-5 分） |

**8 维度预分类：**

| 维度 | 说明 |
|------|------|
| 合同效力 | 主体资格、审批登记、格式条款 |
| 价款支付 | 定价机制、支付条件、发票 |
| 交付验收 | 交付标准、验收程序、质量保证 |
| 违约责任 | 违约情形、违约金、损害赔偿 |
| 知识产权 | 权属、许可、侵权责任 |
| 保密义务 | 保密范围、期限、违约后果 |
| 争议解决 | 管辖、仲裁、法律适用 |
| 合同终止 | 终止条件、清算、后续义务 |

### Step 2 — 全文通读与交易理解

通读合同全文，系统梳理：

1. **合同主体**：当事人名称、住所、法定代表人
2. **标的**：交易对象、数量、质量
3. **价款**：金额、币种、支付方式、支付时间
4. **履行**：交付/服务方式、地点、期限
5. **验收**：验收标准、程序、异议期
6. **违约**：违约情形、违约金、损害赔偿计算
7. **终止**：终止条件、提前终止、清算安排
8. **担保**：保证、抵押、质押
9. **争议解决**：管辖法院/仲裁机构、法律适用
10. **附件**：附件清单、效力优先级

### Step 3 — 效力审查（优先）

> 核心原则：**效力问题优先于条款优化**

五项必查内容：

| 检查项 | 审查要点 |
|--------|----------|
| 名实不符 | 循环买卖、名为买卖实为借贷、让与担保 |
| 关联交易 | 不合理低价、利益输送、关联方担保 |
| 格式条款 | 排除对方主要权利、加重对方责任、未尽提示说明义务 |
| 审批登记 | 合同效力 vs 物权变动的区分、行政审批要求 |
| 合同成立 | 当事人、标的、数量（合同成立三要素） |

### Step 4 — 条款审查（正反两面法）

对每项权利义务进行三层审查：

```
正面 → 正常履行时，权利义务是否清晰？
反面 → 无法履行时，救济措施是否明确？
纵深 → 救济不被执行时，还有什么保障？
```

**审查五道门（Gates）：**

#### Gate 1：主体审查

- 主体名称与印章是否一致
- 签署人是否有授权
- 表见代理风险
- 一人公司特殊要求（财产独立证明）
- 关联担保的决议要求

#### Gate 2：条款审查

- 价款支付：金额、条件、发票
- 交付验收：标准、程序、异议期
- 违约责任：情形、违约金比例、赔偿范围
- 合同终止：条件、清算、后续义务
- 担保保险：范围、期限
- 送达通知：地址、方式、生效时间

#### Gate 3：一致性审查

- 正文与附件是否一致
- 金额、数量、期限是否前后对应
- 定义术语是否一致使用
- 引用条款是否准确

#### Gate 4：立场审查（吸纳自 claude-legal-skill）

基于我方立场评估每条条款的风险方向：

| 立场 | 关注重点 |
|------|----------|
| 买方/委托方 | 付款条件是否过于严苛、验收标准是否合理、知识产权归属 |
| 卖方/受托方 | 交付标准是否过高、违约责任是否过重、回款保障 |
| 出租方 | 租金调整机制、解约条件、维修责任 |
| 承租方 | 转租限制、装修补偿、提前退租条款 |

#### Gate 5：缺失保护检测（吸纳自 ai-legal-claude）

检查合同是否缺少关键保护条款：

| 合同类型 | 应有条款 |
|----------|----------|
| 买卖合同 | 质量异议期、风险转移、知识产权保证 |
| 服务合同 | 服务标准 SLA、人员变更通知、知识成果归属 |
| 租赁合同 | 维修责任、优先续租、装修处理 |
| 投资协议 | 反稀释、优先清算、信息权、共同出售 |
| 保密协议 | 保密期限、除外事项、违约救济 |
| 所有合同 | 不可抗力、通知送达、争议解决、合同终止 |

### Step 5 — 风险评估（六维评价）

对每个发现的风险进行六维评价：

| 维度 | 说明 | 评价标准 |
|------|------|----------|
| 风险性质 | 属于哪类风险 | 效力/合规/交易结构/争议解决/文本 |
| 风险敞口 | 最坏情况损失 | 量化到金额或百分比 |
| 发生概率 | 基于规则明确度、司法趋势、类案裁判 | 高/中/低 |
| 可规避性 | 能否通过结构调整或条款修改消除 | 可完全规避/可部分缓解/不可规避 |
| 商业权衡 | 客户目标与替代方案 | 风险是否值得承担 |
| 紧迫程度 | 处理时间窗口 | 立即/近期/持续监控/长期 |

**风险等级判定：**

| 等级 | 标识 | 条件 |
|------|------|------|
| 🔴 严重 | 高敞口 + 高概率 | 必须修改，否则建议不签署 |
| 🟡 重要 | 中敞口或中概率 | 建议修改，有替代方案 |
| 🟢 一般 | 低敞口 + 低概率 | 可接受，建议关注 |
| ⚪ 合规 | 无风险 | 符合市场标准 |

### Step 6 — 修订路由（修订方式决策）

对每个审查意见，通过决策树确定修订方式：

```
问题 1：能否直接替我方修改？
  → 是：问题 2
  → 否：用批注

问题 2：是否涉及商业判断？
  → 是：用批注列出选项
  → 否：问题 3

问题 3：对方是否会接受？
  → 很可能接受：修订模式（Track Changes）
  → 可能接受：修订模式 + 提醒客户
  → 不太可能接受：用批注

问题 4：是否有多种合理方案？
  → 是：批注列出各方案 + 推荐意见
  → 否：直接修订
```

**修订模式适用场景：**
- 笔误/错别字/日期格式/过时法律名称
- 对我方有利且对方大概率接受的条款补充（送达确认、印章效力、陈述保证、反贿赂等）

**批注模式适用场景：**
- 涉及商业取舍的重大风险
- 条款前后矛盾
- 需要客户决策的多种方案
- 待核实的事实

### Step 7 — 输出三件套

最终输出三个 .docx 文件：

#### 1. 审查标注版合同（修订模式 + 批注）

- 使用 Word 修订模式标注所有修改
- 使用批注说明修改原因和风险提示
- 保留原文格式不变

#### 2. 法律意见书

五个模块：

| 模块 | 内容 |
|------|------|
| 风险概览 | 风险统计卡片、风险类型分布、综合风险等级 |
| 合同基本信息 | 当事人、标的、金额、期限 |
| 逐条意见表 | 序号 → 风险类型 → 审查条款 → 风险描述 → 修改建议 → 风险等级 |
| 综合评价 | 优势/风险分析、重大风险提示、谈判要点、签约后注意事项 |
| 法律依据 | 引用的法律法规、司法解释、指导性案例 |

#### 3. 法律分析（内部参考）

- 每个修订点对应的法条、司法解释、类案裁判
- 供律师内部参考，不交付客户

## 风险标签体系（15 类）

### 效力与合规（5 类）

| 标签 | 覆盖范围 |
|------|----------|
| 合同效力 | 名实不符、违反强制性规定、恶意串通 |
| 格式条款 | 提示说明义务、排除主要权利 |
| 主体授权 | 印章、签字权限、表见代理 |
| 关联交易 | 利益输送、不公允定价 |
| 合规审查 | 行业准入、外资限制、反垄断 |

### 交易结构与履行（5 类）

| 标签 | 覆盖范围 |
|------|----------|
| 价款支付 | 定价、支付条件、发票 |
| 交付验收 | 交付标准、验收程序、质量保证 |
| 违约责任 | 违约金、损害赔偿、免责事由 |
| 合同终止 | 终止条件、清算、后续义务 |
| 担保增信 | 保证、抵押、质押、保证金 |

### 争议解决与文本（5 类）

| 标签 | 覆盖范围 |
|------|----------|
| 争议解决 | 管辖、仲裁、法律适用 |
| 知识产权 | 权属、许可、侵权责任 |
| 定义附件 | 术语定义、附件效力、一致性 |
| 文本一致 | 正文与附件、金额/期限前后对应 |
| 文字格式 | 错别字、日期格式、条款序号 |

## 市场基准参考（吸纳自 claude-legal-skill）

| 条款 | 标准 | 警示 | 问题 |
|------|------|------|------|
| 违约金比例 | 不超过损失 30% | 30%-50% | 超过 50% 或过高 |
| 质量异议期 | 收货后 15-30 天 | 7-15 天 | 少于 7 天或未约定 |
| 付款期限 | 验收后 30 天 | 验收后 60 天 | 预付全款 |
| 竞业限制 | 1-2 年 + 合理补偿 | 2-3 年 | 超过 3 年或无补偿 |
| 保密期限 | 2-5 年 | 5-10 年 | 永久保密 |
| 自动续期通知 | 提前 60-90 天 | 提前 30 天 | 少于 30 天 |
| 不可抗力 | 列举 + 兜底 | 仅列举 | 未约定 |
| 管辖约定 | 被告住所地/合同履行地 | 约定己方有利 | 约定对方所在地 |

## 可谈判性评级（吸纳自 claude-legal-skill）

| 等级 | 说明 | 典型条款 |
|------|------|----------|
| 🟢 高 | 通常可以谈 | 付款期限、质量异议期、保密期限、送达地址 |
| 🟡 中 | 取决于双方地位 | 违约金比例、管辖约定、知识产权归属、竞业限制 |
| 🔴 低 | 很少能改 | 法律强制性规定、行业监管要求、格式合同核心条款 |

## 硬约束（10 条禁令）

1. **禁止**跳过全文通读直接审查
2. **禁止**跳过效力审查
3. **禁止**先写意见再补法律依据
4. **禁止**修改原始合同文件（必须另存为新文件）
5. **禁止**用 .md 作为最终输出格式（必须 .docx）
6. **禁止**给出笼统的"高风险"评价（必须六维评价）
7. **禁止**给出"签/不签"的结论性建议（律师分析利弊，客户做决定）
8. **禁止**引用不存在的法条或案例
9. **禁止**在未匹配到客户规则时套用其他客户偏好
10. **禁止**跳过一致性审查（正文 vs 附件、金额/期限前后对应）

## 风险提示用语

审查意见中使用以下规范用语：

| 风险等级 | 措辞风格 |
|----------|----------|
| 🔴 严重 | "本条款存在重大法律风险，建议修改为：[具体方案]。理由：[法律依据]" |
| 🟡 重要 | "本条款对我方不利，建议修改为：[具体方案]。如对方不同意，可考虑：[备选方案]" |
| 🟢 一般 | "本条款基本合理，建议关注：[注意事项]" |
| ⚪ 合规 | "本条款符合行业惯例/法律规定" |

## 输出目录结构

```
审查报告_YYYYMMDD/
├── 审查标注版_合同名.docx      # 修订模式 + 批注
├── 法律意见书_合同名.docx      # 五模块法律意见
├── 法律分析_合同名.docx        # 内部参考（不交付客户）
└── 审查摘要.md                 # 快速预览（非正式文件）
```
