# Changelog - 合同审查 Skill

所有对此 skill 的更改都将记录在此文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，

## [1.0.0] - 2026-08-01

### 新增

- 初始版本发布
- 7 步审查流程：客户识别 → 全文通读 → 效力审查 → 条款审查 → 风险评估 → 交互确认 → 输出
- 效力审查优先原则（名实不符、关联交易、格式条款、审批登记、成立三要素）
- 正反两面法 + 五道门条款审查（主体、条款、一致性、立场、缺失保护）
- 六维风险评估（风险性质、敞口、概率、可规避性、商业权衡、紧迫程度）
- 交互确认机制：分析完成后先列出发现，等用户确认后再生成文件
- 修订模式（Track Changes）与批注（Comments）混用支持
- 所有修订和批注以 "Lawyer" 身份标注
- 输出文件命名：`{原文件名}[修订版]V1_{YYYYMMDD}.docx`
- 市场基准参考（违约金、质量异议期、付款期限等 8 项）
- 可谈判性评级（高/中/低三级）
- 15 类风险标签体系
- 风险分类详细参考资料（references/risk-categories.md）
- 基础报告生成脚本（scripts/generate_report.py）

### 设计来源

- contract-review-pro (210⭐)：7 步流程、效力优先、正反两面法、六维评估
- claude-legal-skill (390⭐)：立场感知、市场基准、可谈判性评级、缺失保护检测
- ai-legal-claude (1602⭐)：颜色标识、多维度分析

### 已知限制

- Track Changes 的 OOXML 实现尚未完成（generate_report.py 中为基础骨架）
- 不支持扫描版 PDF（需要 OCR 预处理）
- 复杂表格内条款的审查可能需要手动调整
- 长合同可能需要分段审查（受上下文窗口限制）
